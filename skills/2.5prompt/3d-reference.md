# 3D 运镜参考（2.5prompt 分支）

写提示词前，先用可预览的 3D 场景把镜头、走位和节奏定下来，导出参考视频一起喂给 Seedance。只在用户选择要做 3D 时走这个分支；案例见 `references/3d-examples.md`。

## 一、工作流程

1. 读台词和剧情。
2. 先列逐段镜头与走位方案（第二节模板），给用户确认。
3. 出可在网页预览的 3D，再导出参考视频。
4. 用户确认 3D 后才写提示词。
5. 之后改镜头或动作时，3D 和提示词同步改。

## 二、模板

| 时间 | 镜头（机位、焦距、推拉） | 角色（位置、朝向、动作） | 主视角（位置、手） | 其他元素 |
|---|---|---|---|---|
| 0-x秒 | | | | |

## 三、写法原则

1. 3D 只决定镜头、走位和节奏，不决定外形。
2. 外形是关键的元素不放进 3D，或用一眼就看得出是占位的标记代替。
3. 重点信息用推拉特写聚焦，不全程固定机位。
4. 角色面朝镜头，身体朝向服从走位。
5. 群体运动要有个体差异，速度和轨迹各不相同，有停顿，不走匀速直线。
6. 动作节奏干脆，倒地的速度、方向、距离符合真实惯性。
7. 人物之间的接触先走位靠近，再写清手的位置。
8. 3D 里的道具状态和提示词保持一致。
9. 视频时长和提示词总时长一致。
10. POV 镜头以水平转头为主，上下转动限定角度范围，并和提示词写的范围一致。
11. 会开合的东西，开合方向和铰链位置与提示词一致。
12. 角色带主视角移动时，做出完整的换位和转身过程，不瞬移。

## 四、默认值

| 项目 | 默认 |
|---|---|
| 起点 | 沿用 `运镜参考/` 下已有的模板 html 和 `export_video.py` |
| 输出 | 网页 + 参考视频放到本次包装的工程目录，文件名和文件夹名都用中文，交付后打开目录 |
| 喂给 Seedance | 用纯净版：只有 POV 画面，无文字、无红色 |

## 五、禁令表

| 3D 里出现 | 处理 |
|---|---|
| 方块、几何体代替的生物或道具 | 这一段不喂 3D，或在提示词里声明它只代表位置 |
| 和提示词冲突的动作 | 以提示词为准，回头改 3D |

## 六、检查清单

- [ ] 时长和提示词一致
- [ ] 镜头有推拉
- [ ] 群体运动有差异和停顿
- [ ] 倒地的方向和距离合理
- [ ] 接触前先走位
- [ ] 关键外形没有混进 3D
- [ ] 上下转动在规定范围内
- [ ] 开合方向、带人移动过程和提示词一致
- [ ] 喂给 Seedance 的是纯净版
