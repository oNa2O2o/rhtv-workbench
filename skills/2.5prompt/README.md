# 2.5prompt

把台词和大概情节写成 **Seedance 2.5** 可直接粘贴的 POV 视角分幕视频提示词，并输出独立的台词中文对照版。

适用：POV 主视角、角色对镜头说话、多幕态度反转的买量短视频。

## 安装
把本仓库放到 skills 目录（如 `.agents/skills/2.5prompt/`），触发词：`/2.5prompt`、`seedance提示词`、`视频提示词`、`写提示词`、`分幕提示词`、`POV提示词`。

## 文件
- `SKILL.md` — 规则与输出格式
- `references/examples.md` — 示例
- `3d-reference.md` — 3D 运镜参考分支
- `references/3d-examples.md` — 3D 运镜参考案例
- `CHANGELOG.md` — 版本记录（每个版本有 git tag，可回调）
