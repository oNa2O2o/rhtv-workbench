# 2.5prompt：Seedance 2.5 POV 分幕提示词

输入：**台词 + 大概情节**（可能附带角色图、场景图、音频的编号）。
输出（两个独立代码块）：
1. **提示词**：可直接粘贴到 Seedance 2.5 的完整提示词
2. **台词中文对照**：按幕、按时间列出原文台词 + 中文意思

---

## 一、工作流程

1. **读输入**，提取：目标语言（日/韩/英，根据台词判断）、总时长、幕数、角色设定、主视角设定、地点、参考素材编号（@图片N / @音频N）。
2. **主动问一句要不要先做 3D 运镜参考**；要就按同目录 `3d-reference.md` 分支先出 3D，确认后再写提示词。
3. **缺信息就补默认值**（见第三节），不要为了小事反复追问。
4. **必须先问的情况**（只有这些才停下来问）：
   - 画风（二次元 / UE5 渲染 + 真实环境 / 全部真人实拍），和 3D 一起问
   - 出现 IP / 版权内容（如霍格沃兹、哈利波特、知名动漫角色、真实明星）→ 问：照写，还是改成原创设定？
   - 台词看不出目标语言，或台词只给了中文但没说要翻成哪种语言
   - 参考素材编号对应关系不明确（例如提到"换装后"但没给对应图片）
5. **按第二节模板写提示词**，台词保留目标语言原文，不加引号以外的修饰。
6. **跑第五节检查清单**，修正后再输出。
7. **用户反馈成片问题时，先汇报修改方案，确认后再改**；每次改版都输出完整提示词，不只给改动段。
8. **输出**：提示词代码块 + 台词中文对照代码块；如有自动处理（删掉了哪些禁令、修正了哪些错字），在最后用 1-3 行说明。
9. **用户确认合格后**，进入第七节「合格后复盘」。

各层按顺序排列，方括号内为可选或替换项。

【⑧ 分幕】（每幕一段）

### 写法规则

- **时间轴**：从 0s 开始，前后连续不重叠，最后一幕的结束时间 = 总时长。每段台词通常 2-3s。
- **单句结构**：动作 → 表情 → 语气 → `说：台词`。一个时间段内只写一个主要情绪。
- **衔接词**：下一个动作统一用"角色说完之后，……"开头，强制让模型按顺序表演；每幕结尾那一段也必须以"角色说完之后，"开头，否则台词没说完就转场。
- **幕尾即定格帧**：幕尾停顿的那一帧会直接作为选项定格帧，写清停顿时稳定的姿态和表情，让这一帧本身可用。同一份提示词要跑多个版本时，幕尾停顿再多留 0.5s：各版本台词快慢能差到 1.3s，末句会说到幕尾，给包装切点留余量。
- **主体指代**：只用"角色"和"主视角"两个称呼，配角写明身份。动作的发起方和看向谁必须写对。
- **台词**：保留目标语言原文；气声、拖长、压低声音写在"说"前面。
- **叙事节奏**：角色态度逐幕变化，最后一句台词作为钩子。
- **空间写清方位**：写明谁在哪、各自身后是什么、光从哪边来。
- **机位跟着人物关系定**：身高差和站/坐姿态决定俯视、仰视或平视；主视角位置固定，视线可跟随角色动作转动。
- **节奏紧凑**：不留空镜，关键反应的停顿不算空镜；没有台词的段落，用眼神和肢体表现内心戏。
- **改版按实测排时间**：改版时按上一版成片里台词实际时长重排时间轴，不按估算。
- **情绪按幕递进**：后面才出现的情绪，前面不提前出现。
- **过审**：敏感部位不进前景，用视线带过。
- **易漂移的人设元素**（发型、配饰等）写明"全程保持"。
- **形态切换**：角色会切换形态时，每段动作和神态描写都要符合这一段当前形态的设定。
- **光影词库**：正面柔光、侧逆光、逆光、背光、发丝光、伦勃朗侧光、体积光；影调：亮调 / 中调 / 暗调。

### 写法原则

1. 参考素材能决定的不用文字重复，参考素材决定不了的必须用文字写死。
2. 喂给模型的参考会压过文字，不想被照搬的东西就不放进参考，或在文字里声明它只代表什么。
3. 没有参考图的人物和形态必须写全具体外形，否则模型会借用画面里已有的参考。
4. 题材的识别特征要有专门的展示时刻，不能只出现在描述里。
5. 奇幻、非人元素写得越克制写实越可信，夸张会显假。
6. 每个动作先写动机，表演从动机和人设性格出发，不写孤立的姿势。
7. 动作写完整的起、中、落，不跳过过程；道具和外观状态全片越少变越稳，变了就写清怎么变、之后去哪。
8. 位移、倒地、接触都要符合真实的距离、方向和惯性。
9. 镜头手法写它的视觉特征，不只写名字；推拉变焦的幅度和频率宁小勿大。
10. 紧张感靠人物的反应营造，不靠外加的音效和特效。
11. 遇到新问题，优先改分幕里的正向描写，不往全局行堆禁令。
12. 位置和距离用参照物描述（窗边原地、墙根、窗台在腰部高度），不写米数。
13. 躲藏或遮挡要写清遮挡物的高度和身体低于它的姿态。
14. 开场铺垫不超过 1 秒，角色 1 秒内出场。
15. 被发现、对视、吞咽这类关键反应单独给 1–2 秒，不和台词挤在一段，不够就加长总时长。
16. POV 镜头以水平转头为主，上下转动必须写明角度范围，推近靠变焦。
17. 表情只写情绪词（玩味、戏谑、试探），靠眼神和肢体表演，不写笑、嘴角这类五官动作。
18. 角色带着主视角移动（拉、推、引路）时，写清两人位置怎么交换、镜头朝向怎么转。
19. 门、窗、柜等会开合的东西，写清朝哪边开、铰链在画面哪一侧。
20. 迭代跑量素材时，先问用户怎么迭代：保留原片的哪些部分（台词、场景、镜头语言、节奏），替换哪些部分，确认后再写。
21. 总时长先按模型上限定死，再按每幕台词的音节数分配时长，日语约每秒 7 个音，需要逐个念出的音每个另加 0.4s。

## 三、默认值（用户没给时使用）

| 项 | 默认 |
|---|---|
| 主视角 | 与台词语言对应国家的男性，身份按剧情定，不出镜；从头到脚逐项写外形和服装，写明声音性别 |
| 变焦 | 每次 1.5–1.8 倍，全片不超过 3 次；先虚焦后对焦、背景虚化，慢推慢拉 |
| 声音 | 不加惊吓音效和恐怖配乐；非人角色默认不出声 |
| 画风 | 不设默认，开工时问用户 |
| 调色 | 写胶片型号，如：柯达2383、富士Eterna 250D、柯达Vision3 500T |
| 镜头 | 11mm超广角，不要黑边，画面四角无暗角，手持拍摄，镜头全程明显晃动，任何时候画面都不能静止 |
| 俯仰 | 默认俯仰角固定只水平转；需要上下看时写明范围，如「低头不超过30°、抬头不超过15°」 |
| 画面效果 | 体积光，体积雾，空气中漂浮的尘埃，色散 |
| 转场 | 同场景不转场；换场景渐隐黑幕；幕尾停顿 0.5-1s |
| 总时长 | 按台词量估算，每句约 2-3s；用户给了就按用户的 |
| 音频 | 用户提供了 @音频 才写，不要自己编号 |

## 四、禁令冲突处理（核心规则）

**原则：分幕需要什么，就把对应的禁令从全局约束行里删掉。** 分幕描写优先，不改写分幕内容。

| 分幕里出现 | 从全局行删掉 |
|---|---|
| 皱眉 | 禁止角色出现皱眉 |
| 脸红、两颊通红、害羞泛红、眼眶泛红 | 不整条删：分幕只写「脸颊微微泛红」，全局行「禁止脸红」改为「禁止夸张脸红」 |
| 大笑、捧腹 | 禁止夸张大笑 |
| 表情全用情绪词表演 | 「禁止夸张大笑」可换成「角色不做刻意的面部表情，情绪通过眼神和肢体动作表演」 |
| 眼睛发光、魔法光效、闪光、寒气/雾气涌出等 | 禁止出现特效 |
| 推拉、变焦、浅景深、特写、过肩、摇镜等运镜 | 固定镜头，禁止推拉摇移 |
| 画面上的文字、标语、字幕 | 禁止出现文案 |
| 多幕 + 转场（黑幕/硬切） | 保留"一镜到底"（表示每幕内部不切镜头），不删 |

注意：
- "画面效果"里的体积光、体积雾、尘埃、色散属于画面氛围，**不算特效**，不触发删除。
- 新问题优先用分幕描写解决，不往全局行加新禁令。
- 每次删除禁令，都在输出末尾的说明里写一行：`已删除禁令：XX（因第N幕有"XX"）`。

## 七、合格后复盘

用户明确确认提示词合格（如"可以了""合格"）后，自动执行：

1. **整理更新点，先给用户确认，不直接改**，分两部分：
   - **通用原则** → 改 `SKILL.md`。只写原则，一条一行，不写具体执行步骤；能并入已有条目就不新增，保持 skill 精简。
   - **本次任务** → 改 `references/examples.md`。新增案例：最终提示词 + 台词对照 + 3-5 行踩坑记录。
2. **用户确认后**：
   - 按确认内容修改文件。
   - 升 `version`：新增原则或流程升次版本（1.1.0 → 1.2.0），只加案例升修订号（1.1.0 → 1.1.1）。
   - 在 `CHANGELOG.md` 顶部追加一条：版本号、日期、改动要点。
   - 推送：同步到仓库 `oNa2O2o/2.5prompt`，commit 信息写版本号和改动要点，打 tag `v<版本号>` 并推送 tag。
3. **回调旧版本**：`git checkout v<版本号> -- SKILL.md 3d-reference.md references/` 后复制回 skill 目录。
