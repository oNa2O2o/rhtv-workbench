# 3D 运镜参考模板

来源：261111-JP-病娇女教师（保健室帘内 POV，两幕 27.9s），用户 2026-11-12 验收通过的那一版。走位和每轮改了什么见 `references/3d-examples.md` 案例 4。

## 文件

| 文件 | 作用 |
|---|---|
| `保健室_3D运镜参考.html` | 模板网页：场景 + 角色三个大块 + 关键帧表。浏览器直接打开，可拖进度条预览 |
| `three.min.js` | three.js，必须和 html 放在同一个文件夹 |
| `export_video.py` | 导出纯净版参考视频（24fps），或截指定时刻的画面 |
| `views.py` | 出主视角 / 侧视 / 俯视检查图，看转向和脚有没有着地 |
| `speedcheck.py` | 量角色和镜头的最快速度 |

## 开新工程

1. 把 `保健室_3D运镜参考.html` 和 `three.min.js` 复制到工程的 `02_提示词/3D运镜参考/`，html 改名成 `<场景>_3D运镜参考.html`。三个脚本不用复制，直接从这里跑。
2. 按下面两节改场景和关键帧表，其余代码不动。
3. 依次跑 `speedcheck.py` → `views.py` → `export_video.py`。

网页地址参数：`?clean` 纯净版（没有字幕条和进度条，喂 Seedance 用这个）；`?side` 侧视、`?top` 俯视（调试用，红块是主视角的头，红色小块朝主视角正前方）。

## 改场景（html 里「房间」「病床」「帘子」这几段）

- `box(宽, 高, 深, 颜色, x, y, z)`，单位是米，按真实尺寸搭。坐标：主视角坐在原点附近，正前方是 −Z，右手边是 +X，病床在身后（+Z）。
- 模板里的尺寸：床面高约 0.5 m，帘轨高 2.2 m，正面帘子在 `CUR_Z = -1.2`（一臂多远），帘轨半宽 `RAIL_X = 1.2`，推拉门在右墙 x = 2.75。换场景时用同样的方式按真实距离摆。
- 门、帘子这类会开合的东西用一条关键帧轨道驱动（模板里是 `curEdge`：−0.3 合上，0.95 拉开）。

## 改关键帧表（html 里 `hip` 到 `SEGS` 这一段）

- `track([[秒, 值], …])` 是三次 Hermite 插值：关键帧之间速度连续；相邻两段有一段静止或方向反过来时，这一点速度自动为 0，起步和停下自带缓冲。
- 角色
  - `hip`：髋部位置 [x, y, z]。站着 y = 0.9、坐床沿 y = 0.62；y 决定脚离不离地，改了要看侧视图。
  - `yaw`：下半身朝向（度）。0 / 360 = 面朝主视角，180 / 540 = 背对主视角。
  - `tW`：上半身朝向（世界角度），和下半身分开写：坐下时下半身背对床，上半身一直朝着主视角。
  - `lean` 上身前倾，`legPitch` 腿块（0 = 站，−45 = 坐在床沿、腿往身前斜着落到地面），`headTilt` 歪头。
- 朝向的写法：角度数值连续写，转向方向写死。例如从 180 转到 357 就是往一个方向转 177°，不要写回 0，否则会反着转。先在俯视图上想清楚往哪边转角度最小，再写数值。文件里有一个 `shortest()` 小函数（把相邻关键帧换算到 ±180° 以内），模板没有调用它，验收版的朝向都是手写的连续角度。
- 跪床沿这类一个腿块做不出来的姿势：3D 里保持站姿俯身，只写进提示词。腿块往后翻会像飘在空中。
- 镜头
  - `camPos`：主视角头部位置，坐 1.15、站 1.62。
  - `camYaw`：水平转头，正数向左、负数向右。`camPitch`：俯仰，正数抬头。`camZoom`：变焦倍数。
  - 主视角走路时的起伏只加在 `setTime` 里 `wk` 那一行列出的时间段，改了走路时间要同步改这一行。
- `SEGS`：预览时左上角显示的分段说明，和提示词时间轴一一对应。
- 总时长：改 `DUR`，同时改文件开头进度条的 `max="27.9"`。

## 跑脚本

需要：Python 装 playwright（连本机 Chrome，`channel="chrome"`，不用 `playwright install`）和 Pillow（`views.py` 用）；`export_video.py` 要 ffmpeg 在 PATH 里。脚本用 swiftshader 软件渲染，Chrome 用 GPU 截图会全白。

```bash
export PYTHONIOENCODING=utf-8
S="<2.5prompt 目录>/assets/3d"
H="<工程>/02_提示词/3D运镜参考/<场景>_3D运镜参考.html"

# 1. 速度表：打印角色走路、升降、转身、上半身转向，镜头移动、升降、转头的最快速度和时刻
python "$S/speedcheck.py" "$H"

# 2. 检查图：时刻用逗号隔开；视角写 pov / side / top，每个视角一行
python "$S/views.py" "$H" "<输出前缀>" 1,2.6,9,18.4,23.9 pov,side,top
#   出 <输出前缀>.png 拼图，另有每格单张 <输出前缀>_<视角>_<秒>.png

# 3. 导出纯净版参考视频（时长自动读 DUR）
python "$S/export_video.py" "$H" "<工程>/02_提示词/3D运镜参考_<时长>s_纯净版.mp4" video
#   只截几帧看：python "$S/export_video.py" "$H" "<输出文件夹>" 1,9,18.4
```

速度对照（本片定下的真人速度）：走路约 1 m/s（验收版最快 1.17 m/s）、站起约 1.2 s、坐下约 0.8 s、转头不超过约 130°/s、转身不超过约 180°/s。`speedcheck.py` 只打印不判定，自己对照；超了就改关键帧再量，不导出。
