# 案例：JP · 追放された女騎士（B，同剧本 5 角色版本）

> 版式 B ｜ 参考案例 ｜ 脚本：本目录没有脚本。原工程 `包装素材v1/脚本/` 里的 gen.py、bridge.py、endcard.py、mix_bgm.py 可参考（路径写死原工程，复用改成 `$P`）；patch.mjs 依赖已停用的编辑器 API，不能运行，写工程这步改成 to_timeline → `scripts/render.py`。

## 本片参数（只属本片，不照搬）
- 地区 JP，男性向，每条 46.25 s，1080×1920。
- 结构：剧情（Seedance 27.5 s POV 原片；选项 1 定格 2.6 s 点「粥をあげる」；选项 2 定格 3.0 s 不点）→ 定格缩进手机 + 划卡承接 6.8 s → 尾板 5.8 s。
- 数值：只用「警戒度」（往下降的数值条，打法见 library/打法.md），选后 −30、递粥 −30、敲门 +50、撞见喝粥 −50，时间点对准画面动作。
- 口播：只在承接和尾板，克隆音色「日语可爱竹马」（用户指定，ID 见 reference/环境.md）。
- BGM：剧情、承接+尾板各一首，口播处整句平滑压低；实现是原工程 `mix_bgm.py`（按口播能量找语音区间，分段平滑闪避，不用侧链）。
- 工程：`$WORK_ROOT/2026年11月3日MM-JP-追放された女騎士`（其余版本工程名加 `-2金发兜帽` … `-5红发发带`）。脚本：gen.py 图层、bridge.py 承接、endcard.py 尾板、mix_bgm.py 闪避、export_all.sh 批量导出。
