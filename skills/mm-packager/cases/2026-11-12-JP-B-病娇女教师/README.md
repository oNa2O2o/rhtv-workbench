> 版式 B ｜ 参考案例（多版本时间映射、三卡片尾板 endcard3、用户音效优先）｜ 状态：版本1（v1 棕发眼镜）2026-11-12 验收出成品；版本2–4 已出预览，未验收 ｜ 脚本：本目录 6 个脚本是工程 `05_包装/脚本/` 原样存档，路径写死原工程，本目录不能直接运行；能复用的部分已通用化进 Skill（见下表），新片用 Skill 里的脚本，不照抄这里。

## 本片参数（只属本片，不照搬）
- 地区 JP，男性向，1080×1920，30 fps。RHTV 工作台工程 `261111-JP-病娇女教师`，`$P` = 工程下的 `05_包装/`，母版从 `../04_母版` 取。
- 原片：Seedance 480×854、约 28 s POV（保健室帘内），放大成 `素材/视频_N_1080.mp4` 用。
- 结构（版本1 成片秒）：原片 0–12.333 → 选项定格 1 12.333–14.933（点「どこも悪くないです、帰ります」）→ 原片 14.933–30.5（= 原片 12.333–27.9，成片 = 原片 + 2.6）→ 选项定格 2 30.5–33.1（不点）→ 33.1–33.7 缩进手机 → 产品 UI 划卡 33.4 起 → 三卡片尾板 E0 = 41.733 → 结束 46.633。
- 数值「逃走成功率」45 → 15（−30 在 2.767）→ 50（+35 在 16.6）→ 1（−49 在 20.1，落锁）；钟声拟声字 19.2，落锁拟声字 20.1。第一个选项 12.4 s 出现，超过 B 规则「≤ 5 s」：剧本把选项排在第一幕两句台词之后，原片按真人速度做不到更早（口径等用户定，见下方「未定」）。
- 开头不放标题和开场字，只放 Logo（用户两次要求后定的，见修改记录）。
- 屏幕文字：四句台词、两组选项、数值名、卡片标题「保健室の先生」、按钮「今すぐ無料で話す」照全量文案；目标「目標 保健室から脱出せよ」、重点词、hero 标签和简介、拟声字、聊天数由包装补写（`05_包装/补充文案.md`）。
- 口播（克隆音色「竹马」，ID 见 reference/环境.md）：vo1「危険な恋は、MiraiMindで」33.6 s；vo2「背徳感に震える、刺激的なシチュエーション」37.0 s；vo3「あなただけを必要とする先生」片尾 E0 + 1.0（三句都取自口播库，vo3 只把「彼女」换成「先生」）。
- 划卡：陪衬卡 裏切られた女騎士 / レイナ / 未亡人雪女（卡面库原字段），hero = 本片原片整帧（版本1 第 302 帧）。详情页慢推缩放 0.74 → 0.77（37.9–41.0 s）。
- 三卡片尾板：两侧 裏切られた女騎士 / レイナ，中间本片老师；チャット数 中 1,231,846 / 左 987,265 / 右 1,059,130 起跳；文案 = vo3，「あなただけを」白字 + 「必要とする先生」末行金色大字；按钮 0.5 s、文案和口播 1.0 s、商店标 1.5 s，连点在口播说完后。
- BGM：ElevenLabs 两首（故事 `bgm_story`、承接 `bgm_bridge`），都做 `_lite`（80 Hz 高通 + 150 Hz lowshelf −8 dB）；闪避平台 HI 0.30 / LO 0.10。故事 BGM 文件 0–1.25 s 静音、31.8 s 后断，开头借文件 5.567 s 起的段铺 0–2.65（5.80 s 重拍落在 0.233 闪白上），31.78 起重放 30.48 s 起的 1.32 s 接到缩进手机；承接 BGM 文件 11.1 s 后没声，43.47 起按小节续接文件 5.90 s 起的律动。产品 UI mp4 自带音效在口播期间压到 0.22。
- 音效：用户音效收集（进选项/闪白/照相、收钱加分减分清脆响声、正确提示音、气泡提示音、咔嗒清脆点击、科技感空灵音效、回声弹出音效）+ ElevenLabs 生成（门锁、放学钟声、末题钟声、软心跳、滴答、划卡；滴答和划卡 300 Hz 双级高通，心跳 70 Hz 高通 + 120 Hz 轻提）。
- limiter 0.84，成品实测 −18.6 LUFS、真峰值 −1.5 dBTP（ebur128 peak=true）。
