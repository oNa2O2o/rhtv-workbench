# 往期素材卡片库（JP）

划卡陪衬卡、C 尾板、JP 尾板加卡时从这里取。卡面图在 `$RES/library/cards/`，表里写相对 `$RES` 的路径。

## 怎么取卡
- "用近 N 个素材的卡片" = 表里「状态」为"可用"的最新 N 个素材；一个素材有多张卡算 1 个，默认取第 1 张。
- 状态"待补"：缺名字/简介/标签，或简介其实是片尾文案/CTA。要用就由包装补写，补写内容出片前列给用户（日文附中文）确认。
- 状态"不可用（生图来源，待核实 02 审核）"：卡面疑似包装阶段生图，核实是工作台 02 已审核人设图前不用；核实不过就换成原片帧。
- 状态"不作陪衬卡"：旧版片的角色卡，不再用。
- 性向"待确认"：原记录是推断。按性向挑卡时先问用户。

## 收录条件（复盘时写回）
- 素材已交付；名字、简介、标签取自全量文案、swipe.json，或包装补写并经用户确认。
- 同一角色有多个造型只收主版本。
- 卡面来源只填：原片抽帧 / 卡面库 / 02 已审核人设图。原片抽帧挑表情平静、不张嘴大笑的整帧。
- 性向来源只填：文案标注 / 目录名；推断的一律写"待确认"。
- 新素材加在表最上面。
