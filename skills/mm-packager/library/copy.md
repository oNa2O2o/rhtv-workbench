# 往期包装文案库（JP，日期倒序）

用途：
- 包装补写标题、「目标」、片尾文案、按钮、卡片字段时，查往期写法和长度；补写内容仍要出片前列给用户（日文附中文）确认。
- 写 library/cards.md 字段时查原文出处。
- 不是口播来源：口播按 rules/通用.md（剧本已写就用剧本的，否则读 shortdrama-copy/references/投放高效文案.md）。
- 标"旧版·不作参考"的素材只留作记录，不照它的写法。
- 这里是原文，标点照原样；去标点在渲染时做。

格式：日语｜中文。中文均摘自 全量文案.md；标〔译〕的是原文档没有中文、后补的翻译。没有的项写「—」。各项用途：标题 = 第一句台词前出现的字（含开场字、钩子说明字，见 rules/通用.md）；目标 = 选项界面的「目标」，不算标题；字幕主句 = 剧情台词字幕；口播 = 承接和片尾配音；聊天气泡 = 手机屏/app-ui chat 消息；片尾文案、按钮 = 尾板。
