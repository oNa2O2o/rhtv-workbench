# 可选打法

用户验收过的套路，按需选用，不是必须。选了哪条写进本片 `cases/` 记录。
打法里用到的音效/BGM 来源、角色图来源、口播来源、气泡字号按 `rules/通用.md`；字体按 `rules/<地区>.md`（JP 见 `rules/JP.md`）；B 的尺寸按 `rules/B-剧情选择.md`「版面」，C 专属要求按 `rules/C-网感剪辑.md`，这里不重复。

## 转场与开场

### 1. 承接转场备选：推近手机 + 闪白
- 做什么：正片最后 0.6 s 用 scale 关键帧推近画面里角色手上的手机，叠闪白图层，再切产品 UI（app-ui 划卡/聊天）。
- 适合：画面里本来就有手机、想直接"钻进"手机时；默认做法（定格缩进手机）见 rules/通用.md。
- 注意：一样不能硬切〔2026-11-09〕

### 2. 白闪转场
- 做什么：一帧到几帧的白闪，用在幕间、变身、进片尾。
- 适合：所有题材；有硬切、变身、跳时间的地方最需要。
- 注意：用户要求过"幕间要闪白"；闪白音效来源按 rules/通用.md〔2026-10-16〕

### 3. 分屏反差开场（B）
- 做什么：上下两个反差帧 + 斜向标题条 + Logo，独占约 2–3 s，之后接正片，不叠在正片上。
- 适合：B，前后反差明显的剧情（进门前/进门后、平静/暴怒）。
- 注意：开场时长算进第一个选项时间，第一个选项仍要 ≤ 5 s；标题文案按包装补充文案流程先给用户确认〔2026-10-22〕

## 画面风格

### 4. 主色取自画面
- 做什么：主色从角色发色、服装、灯光色里取。
- 适合：所有题材。
- 注意：取画面里已有的颜色更容易融入画面；全片仍只用一套配色（见 rules/通用.md）〔2026-10-21〕

### 5. 简约香槟风（B）
- 做什么：全片无框、无气泡；无框跟脸字幕（白字 + 柔光 + 小箭头指脸）+ 每句重点词 + 犹豫指针 + 闪烁「目标」+ 按幕递进的 BGM（打法 16）；片尾前可接 AI 剧情对话手机屏（打法 7）；全片只有片尾下载按钮是实心按钮。
- 适合：B，逼迫向、强势女角色。
- 注意：选项用 B 默认样式（见 rules/B-剧情选择.md），不用全屏失焦；配色取角色发色（例：银发 → 香槟金）〔2026-10-21〕

### 6. 监控摄像头 HUD
- 做什么：四角细线、机位名（如 `CAM 01 玄関`）、走秒时钟（时间和剧情对上）、暗角、隔行扫描线；识别框跟脸（带入场动画和框内扫描线，标签如 年齢/性別）；字幕做成文字识别效果（逐字乱码 → 正字 + 上浮 + 光标，挂在识别框下方跟着走）；状态值实时小幅跳动，剧情节点的大幅变化照剧本数值；选项加扫描线和半透明底；选项指针用半透明圆圈，点击带波纹；场景过渡用黑幕；所有 UI 统一做广角桶形畸变 + 边缘 RGB 色散。
- 适合：微恐、伪人、悬疑、监视视角。
- 注意：不加 REC（用户："这是摄像头不是录像机"）；HUD 文字用像素体（JP 字体见 rules/JP.md）；微恐题材可用丝滑音效（见 rules/通用.md）〔2026-10-20〕

## 承接与片尾

### 7. AI 剧情对话手机屏（进片尾前）
- 做什么：手机屏上是角色发来的消息 + 原片截帧照片，输入中「…」后弹出新消息。优先用 app-ui chat 模式做；没有产品参考时照试玩广告 UI：灵动岛、居中头像 + 名字 + 在线点、分割线、左侧气泡、图片消息、输入中「…」，配色和字体跟正片统一。
- 口播版：聊天屏 + 口播 + 逐句字幕 → 片尾卡。口播来源和音色按 rules/通用.md（音色由用户选）。
- 适合：B，剧情停在暧昧/悬念处，用"她还在给你发消息"引导下载。
- 注意：消息文字取剧本台词，新加的消息按包装补充文案流程先给用户确认；照片只用原片整帧〔2026-10-21〕

### 8. 网感剪辑尾板（C）
- 做什么：Logo 在顶部且第一帧就在 + 多张角色卡扇形飞入 + 卡底聊天数持续跳涨 + 主角卡高亮 + 口播 + 点击下载。
- 适合：C 网感剪辑；多角色题材（偶像团、后宫）。
- 注意：卡面按 library/cards.md 的卡面来源取，每张卡要有名字和简介；动画做在卡片上，Logo 不动〔2026-11-04〕

### 9. 倒带进片尾
- 做什么：画面倒放回之前某一帧，黑白 → 彩色、扫描线、◀◀ 标记，再展开成片尾卡；片尾卡的图用倒回去的那一帧。
- 适合：B，失败/选错之后"重来一次"的剧情。
- 注意：倒带音效来源和片尾时长按 rules/通用.md；片尾图和剧情逻辑要对上〔2026-10-22〕

## 选项与数值

### 10. 最后一题心跳
- 做什么：最后一题定格画面缩放 + 暗角同步脉动 + 心跳声，越来越快 → 白闪进片尾。
- 适合：B，心动、暧昧、贴脸类结尾。
- 注意：心跳声来源按 rules/通用.md（用户提供的优先，没有用 ElevenLabs 生成）〔2026-10-26〕

### 11. 命令输入框玩法（B）
- 做什么：用户在输入框里打字下命令 → 角色照做、短句回应 → 数值递增，最后一次暴击。
- 适合：B，保镖、执事、恋人这类"听你话"的角色。
- 注意：命令文案、数值名称和幅度照剧本；输入框尺寸按 rules/B-剧情选择.md「版面」〔2026-11-02〕

### 12. 负向数值条
- 做什么：用「警戒度」这类往下降的指标代替好感度，降到底 = 攻略成功。
- 适合：B，戒备心强的角色（逃亡者、敌对方、高冷）。
- 注意：用不用、数值名称和幅度由剧本定；变化时间点对准画面动作〔2026-11-05〕

### 13. 倒计时条末段变红
- 做什么：选项倒计时条最后阶段变红，催促点击。
- 适合：B 所有选项。
- 注意：（原因待补）〔2026-10-26〕

### 14. 表情进度条
- 做什么：代替常驻标题。节点是角色各阶段的表情头像 + 阶段名（如 1日目/2日目/3日目），不加背景底板，随剧情逐个点亮。
- 适合：分天数/分阶段推进的恋爱剧情。
- 注意：头像用原片整帧；可和打法 15 锁钩子连用〔2026-10-19〕

### 15. 锁钩子
- 做什么：最后一个节点上锁；锁最多在入场时动一次；结尾锁飞到画面中心，开锁瞬间直接转片尾；开锁配开锁音效。
- 适合：搭配表情进度条，剧情停在"下一步"之前。
- 注意：不显示解锁后的内容（如「制限解除」），钩子要留住（用户："这是钩子"）；锁一直跳被否过〔2026-10-19〕

### 16. 剧情 BGM 按幕递进
- 做什么：每幕 BGM 逐层加码（压迫律动 → 完整鼓组 → 高潮层），每幕结尾上扬接选项；选项段撤鼓换悬疑 pad；用 ElevenLabs composition plan 分段写。
- 适合：B 多幕剧情选择。
- 注意：幕数照全量文案，不固定三幕；用户嫌 BGM "太平淡了" 时用〔2026-10-21〕

## 角色表现

### 17. 画外音和角色台词分开
- 做什么：角色台词跟脸；POV 主角的画外音放画面底部，用冷色。
- 适合：POV 有主角画外音的剧情。
- 注意：台词气泡字号按 rules/通用.md，B 的其他尺寸按 rules/B-剧情选择.md「版面」；颜色区分的原因待补〔2026-10-26〕

### 18. 角色卡镜头角度
- 做什么：弱势/害羞角色的卡选俯拍帧，强势/高冷/成熟角色选仰拍帧（jp-endcard heroes 的 `angle` 同理：`high` 俯拍、`low` 仰拍）。
- 适合：划卡、JP 尾板、C 尾板里需要多张角色卡区分性格时。
- 注意：只从原片帧和卡面库里挑合适角度，不生图〔2026-10-27〕

### 19. 打击点特效
- 做什么：打击瞬间（巴掌、撞击）震屏 + 闪白 + 会慢慢淡去的屏幕裂纹 + 日文拟声字（如「パァン」）。
- 适合：有巴掌、撞击、摔东西等强动作的剧情。
- 注意：时间点对准原声能量峰和剪辑点；打击音效来源按 rules/通用.md〔2026-10-16〕

### 20. 失败重试流程
- 做什么：倒计时走完不选 → 画面变灰 → 「時間切れ」→ 同位置「説得失敗」卡 → 手指点「リトライ」→ 接倒带进片尾（打法 9）。
- 适合：B，"哄不好就失败"的剧情。
- 注意：每个信息都要停够时间（用户嫌过"节奏太快""叠在一起""进片尾太快"）；第一个选项仍要 ≤ 5 s〔2026-10-16〕

## 跟脸实现

### 21. 跟脸方法选择
- 做什么：要求准就用 YuNet；动漫脸用 `lbpcascade_animeface` + 连续性筛选 / 插值 / 平滑 + 手动锚点；只要大概位置时用人物蒙版最大连通域顶部估头。平滑不能跨硬切。
- 适合：跟脸字幕、识别框、指向角色的标记。
- 注意：蒙版工具和 GPU 环境见 reference/环境.md；生成前出核对图按 rules/通用.md〔2026-10-20/21/26〕
