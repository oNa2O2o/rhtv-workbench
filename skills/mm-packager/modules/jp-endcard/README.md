# jp-endcard · MM-JP 主卡长廊尾板（一镜到底 3D 卡片）

主卡长廊尾板（和 endcard3「三卡片尾板」不是一个东西），17.3 s、1080×1920、30 fps，自带女王02 口播、钢琴弦乐 BGM 和音效。
什么时候用（定方案时问用户，选了才加）、不受片尾 ≤10 s 限制、换文案要重新申请，这些规则见 `rules/JP.md`；本文只写规格和用法。

## 内容（固定，改了要重新验收）
| 时间 | 画面 | 口播 / 字幕 |
|---|---|---|
| 0–3.0 | 光点炸开 → 角色卡网络展开 | あなたの選択が、[展開]を変える |
| 3.2–6.8 | 镜头依次飞到 3 张对比卡（害羞俯拍 / 高冷仰拍 / 成熟仰拍），卡上弹聊天气泡 | 恥じらう子も、冷たい子も、大人の子も。みんな、あなたに[夢中] |
| 6.6–8.2 | 拉远蓄力 → 弹弓式冲进角色卡螺旋长廊 | |
| 8.2–11.9 | 长廊加速穿梭，计数到 1,000,000 | [百万以上]のキャラクターに、あなただけの[特別]を |
| 11.9–13.1 | 所有卡片吸入 MM Logo，Logo 果冻回弹 + 光爆；音乐倒放吸气 → 回弹时正放 | |
| 13.1–17.3 | Logo + 字标，無制限モード 开关 ON，CTA 光线擦出，触控点击 + 水波纹 + 点击音，商店标识 | ここから先は、[あなた次第] |

`[]` 里是强调词（画面上高亮）。文案、口播、时间轴逐句对齐，本模块配置只能换角色卡和卡上气泡。

## 用法
`EC="python $SK/modules/jp-endcard/endcard.py"`（需要 playwright、Chrome、ffmpeg）

```bash
# 默认配置：定稿画面 + 整句平滑混音，几秒出（--legacy-mix = 原样复制 10-27 侧链混音的定稿）
$EC render --out "$P/包装素材_尾板/MM-JP_尾板_定稿.mp4"

# 换角色：先出静帧看，再 render（逐帧渲染约 30 分钟，放后台）
$EC stills --config "$P/包装素材_尾板/尾板配置.json" --out "$P/包装素材_尾板/静帧"
nohup $EC render --config "$P/包装素材_尾板/尾板配置.json" --out "$P/包装素材_尾板/MM-JP_尾板_<配置哈希>.mp4" > "$P/包装素材_尾板/render.log" 2>&1 &
```
- 自定义渲染每帧最多 24 个子帧做运动模糊，约 30 分钟，不能放在 600 s 超时的前台命令里；用 nohup 后台跑，轮询日志。
- 渲染完会在 mp4 旁边写 `<名>_引擎配置.json`，并用 ffmpeg 解码检查一遍。

放进 timeline：尾板 mp4 作为 video clip 接在片尾，`fit: cover`，`start` = 正片结束时间；音频怎么接见 `rules/工程交付.md`「timeline」。

## 配置（全部可省略）
```json
{
  "heroes": [
    {"card": "$P/工程素材/卡面_害羞.png", "tag": "照れ屋", "chat": "え…わ、私でいいの？", "tint": "#F6A3E0", "angle": "high"},
    {},
    {"card": 6}
  ],
  "addCards": ["$P/工程素材/卡面_1.png", "$P/工程素材/卡面_2.png"],
  "replaceAllCards": false,
  "mix": {"duckLevel": 0.35}
}
```
- `heroes`：正好 3 个，顺序对应固定口播「恥じらう子も、冷たい子も、大人の子も」= 害羞 / 高冷 / 成熟；`{}` 表示该位保持默认。
  - `card`：图片绝对路径（上例的 `$P` 要写成实际路径，脚本不展开变量），或内置卡下标（0–26）。
  - `tag`、`chat`：卡上气泡文字（日语），来源见 `rules/JP.md`。
  - `tint`：气泡主色；`angle`：`high` 俯拍（弱势角色）/ `low` 仰拍（强势角色）。
- `addCards`：追加角色图（任意尺寸竖图，自动居中裁成卡片），优先进开场角色网（最多 20 张配角），同时进长廊。
- `replaceAllCards: true`：不用内置卡，只用 `addCards` + `heroes`，卡片总数至少 8 张。
- 引擎配置里的 `extras` 是开场角色网里配角卡的顺序（卡下标列表），由脚本按 `addCards` 自动排，一般不手改。
- 角色图来源见 `rules/通用.md`：只用原片帧、卡面库或工作台 02 已审核的人设图，只裁切不改图。
- `mix`：混音参数，见下节。只改 `mix` 不会重新逐帧渲染。

## 声音
- 内置 BGM（钢琴弦乐）、收尾钢琴弦乐、音效、女王02 口播原样保留，例外规则见 `rules/JP.md`。
- 口播只有 001、002、003、005 四句：004 是早期版本 Logo 段的一句，定稿删掉了（原因待补），文件编号没重排。
- BGM 闪避：按 `config.default.json` 里 `vo[].parts` 的分句时间段生成 BGM 音量包络（整句平滑压低，不用侧链）。默认出片和自定义渲染都用它。

| `mix` 参数 | 默认 | 说明 |
|---|---|---|
| `duckLevel` | 0.35 | 口播期间 BGM 压到的倍数（按原侧链听感估的值，以人声清楚、BGM 还听得到为准） |
| `duckFade` | 0.25 | 句前提前多少秒开始压 |
| `duckHold` | 0.4 | 句末后保持压低多少秒 |
| `duckRelease` | 0.7 | 保持之后用多少秒慢慢回升 |
| `duckMergeGap` | 1.4 | 相邻两句间隔小于这个秒数就并成一段，中间不回升（实际取它和 duckFade+duckHold+duckRelease 的较大值） |

- 按默认参数，四句口播之间的停顿都会并掉：约 0.05–16.2 s 一直压低，之后 0.7 s 回升到 16.9 s。卡片吸入 Logo 的倒放吸气（11.85–13.05 s）也在压低段里，要听一下高潮够不够。
- `$RES/jp-endcard/prebuilt/default.mp4` 本身仍是 10-27 验收时的侧链混音；默认出片只取它的画面（不重编码）再按 `mix` 重混。新混音还没经用户试听验收。
- 只改 `mix`、不改卡：复用定稿画面，几秒出，不逐帧渲染。

## 文件
| 路径 | 说明 |
|---|---|
| `endcard.py` | 命令入口（render / stills）、配置合并、混音 |
| `engine/endcard.js` + `index.html` | Canvas 3D 渲染引擎（定稿代码，2× 超采样 + 自适应运动模糊） |
| `config.default.json` | 定稿配置：27 张内置卡、主卡长廊的主卡位（heroes）、配角顺序、口播分句时间、文案、混音参数 |
| `$RES/jp-endcard/assets/` | 内置角色卡 c01–c27（来源未知）、字体；Logo、商店标改用 skill 内置的 `assets/官方素材/`（同名文件优先用它）。商店标换成两个同尺寸的官方原版后，`prebuilt/default.mp4` 里还是旧标，所以默认配置也会逐帧重渲染（约 30 分钟），渲染好可替换 prebuilt |
| `$RES/jp-endcard/media/audio/`、`media/vo/` | BGM、收尾钢琴弦乐、音效、女王02 口播 |
| `$RES/jp-endcard/prebuilt/default.mp4` | 定稿成片（默认配置直接复制） |

引擎开发目录和全部历史版本在本机，路径见 `reference/环境.md`。
