## GPU 与抠图（本机 RTX 5070）
- rembg（`u2net_human_seg`）走 CPU（rembg 的 CUDA 会 access violation 崩溃）〔2026-10-26〕
- 动漫/角色抠图用 `ZhengPeng7/BiRefNet_lite`，torch CUDA fp16（`.cuda().half()`）跑通过（猫娘、保镖的 matte.py）〔2026-10-26/11-02〕
- faster-whisper 用 GPU 时装 cublas/cudnn 9，并用 `zz_nvidia_dll_path.pth` 把 DLL 路径加进 site-packages（不加会找不到 DLL）〔2026-11-05〕
- asr.py 默认 `--engine scribe`（ElevenLabs，逐字，质量最好），失败自动转 whisper 并说明；whisper 用 medium（`--model medium`、`--threads 2`），ffmpeg 先解成 16k 数组再交给 transcribe；不用 large-v3（本机加载就内存不够），不降级到 small（会幻听）〔2026-11-12〕
- elevenlabs CLI 调用（口播、音效、BGM、scribe）一律串行，不并发（三条 scribe 并发后 OAuth 登录被清，之后 TTS/SFX 全停）；asr.py 里的 scribe 调用已包在 `heavy_lock("elevenlabs")` 里排队〔2026-11-12〕

## Windows 专用
- 先 `export PYTHONIOENCODING=utf-8`（控制台默认 GBK，中文输出会报错）；`python -I` 会忽略这个变量，中文输出改写 UTF-8 文件再读（原因：-I 隔离模式不读 PYTHON* 变量）
- Git Bash 循环里跑 ffmpeg 加 `-nostdin`（不加会吞掉循环的 stdin，只跑第一轮）
- `scripts/open_dir.ps1`、`scripts/figma_login.ps1`、`scripts/figma_close.ps1` 只能在 Windows PowerShell 用：`powershell -NoProfile -ExecutionPolicy Bypass -File $SK/scripts/open_dir.ps1 "<目录>"`
- 环境变量里的 `ELEVENLABS_API_KEY` 没有 music 权限时，要去掉它改走 CLI 登录：bash `env -u ELEVENLABS_API_KEY elevenlabs …`；PowerShell `$k=$env:ELEVENLABS_API_KEY; Remove-Item Env:ELEVENLABS_API_KEY; elevenlabs …; $env:ELEVENLABS_API_KEY=$k`；Python 子进程传一份删掉该键的 env（保镖 audio_gen.py 的写法），Windows 下命令名是 `elevenlabs.cmd`
- OpenCV 读写中文路径用 `cv2.imdecode(np.fromfile(p, np.uint8), …)` / `cv2.imencode(...)[1].tofile(p)`（cv2.imread 不认中文路径）
- 读图工具偶发 ENOENT：先复制到 `$VIEW_TMP` 再读
- 前台命令 600 s 超时：jp-endcard 自定义渲染（约 30 分钟）这类长任务放后台（bash `nohup … &`，或工具的后台运行），轮询日志

## 排错
| 现象 | 处理 |
|---|---|
| `$RES` 读不到 | 查共享盘有没有映射，或把 `MM_RES` 指向本地副本 |
| 日文变细体 / 缺字 | 字体换 `$RES/fonts/` 里带假名的，见 rules/JP.md |
| 混音爆音 / 真峰值超标（render.py 退出码 3） | render.py 默认 limiter 0.84（0.89 编码后真峰值 −0.4 dBTP 不合格）；还超就降音效 volume |
| ElevenLabs music 分段报错 | composition plan 用 `--json`，每段 `duration_ms` ≥ 3000；`--prompt` 报 sections 缺失也改 `--json` |
| OpenCV 没有 CascadeClassifier | 系统是 OpenCV 5：`pip install opencv-python-headless==4.10.0.84 --target $CV4_DIR` |
| Figma 截图返回 `NOT_LOGGED_IN` / 登录过期 | 跑 `figma_login.ps1`（先关旧窗口再弹登录窗），让用户自己在弹窗里登录 |
| 要 gitee 上的原文件 | `curl` 拿 raw 链接：`https://gitee.com/<user>/<repo>/raw/master/<urlencoded路径>` |
| ASR 前段糊成一个词、取不到逐字时间 | 见 rules/工程交付.md（拆片） |
