# B 剧情选择

> 只写 B 独有的做法。版式定义和结构见 SKILL.md；B、C 都适用的做法（字幕、承接转场、声音等）见 rules/通用.md；可选套路见 library/打法.md。尺寸都按 1080×1920，只写范围，单片验收值在 cases/。

## 节奏

- 第一个选项 ≤ 5 s 出现（含开头标题），开头标题、分屏、氛围都不能拖慢它；定方案时在时间表里标出第一个选项的出现时间，并写明为什么不能更早（选项就是 B 的核心玩法）〔2026-10-30〕
- 选项出来后指针先在选项间犹豫 1.5–2 s 再点，不能一出来就点（用户：『切换太快』）〔2026-10-21〕
- 点完后其他选项消失 → 选中项闪烁/高亮 → 约 0.5 s 后回剧情；定格总长 2.5–3.2 s（用户：『点击后过渡太长』）〔2026-10-27〕
- 最后一题可以一直犹豫不点、直接转场留钩子，也可以点；按全量文案标的默认选中/不点做（用户裁决：不写死）〔2026-10-21〕
- 剧情段默认不加口播，口播放在承接和尾板（原因待补）〔2026-11-05〕

## 选项

- 选项默认样式：只出选项、不显示提问；画面中下方胶囊 + 倒计时条；只压暗下半屏，不全屏失焦（原因待补）〔2026-10-27/30〕
- 点击指针用半透明圆圈（白圈 + 深色外环/投影，压在选项胶囊上也要看得清），点击时出波纹，不用实心箭头或手指图标；片尾按钮的点击也用同一个指针（用户否决过 v1 指针；病娇女教师复审：胶囊上的指针看不清）〔2026-10-20/11-12〕
- 需要交代背景时只放一句「目标」，有目标时选项界面显示目标并闪烁强调；全量文案没写就由包装补写，补写和确认流程见 rules/通用.md（原因待补）〔2026-10-21〕
- 选项段声音跟着选项结构走：进定格一记重拍、倒计时期间滴答、点击一记重击；选项段 BGM 也要跟这个时间结构（用户：『BGM 没跟选项节奏』）；音效来源见 rules/通用.md〔2026-10-27〕

## 版面

- 画面中下区（y 960–1440）只放选项 UI：选项、输入框、用户消息气泡、角色回复气泡；数值条不放中下区（这一区符合拿手机的视线和拇指位置）〔2026-11-02〕
- 角色脸偏下时选项 UI 整体下移，输入框中心 ≤ y 1630（不压脸）〔2026-11-02〕
- 台词、数值条、选项 UI、输入框是 B 的重点元素，按下面尺寸做（手机上要一眼看清）〔2026-10-30〕
- 输入框高 130–160；输入框和气泡宽 ≤ 940，左右各留 ≥ 70；同屏消息 ≤ 2 条；气泡和输入框字号见 rules/通用.md（用户验收）〔2026-11-02〕
- 选项胶囊字号 80–88、高 160–180、宽 ≤ 1000（用户验收，70 号被判太小）〔2026-11-02/05〕
- 头顶身份字 56–64，跟着头走（用户验收）〔2026-11-02〕

## 数值条

- 数值名称、触发点、每次变化量和变化后的值都照全量文案，包装不改；包装只管表现和对齐画面（剧本出核心剧情，包装只补全；用户裁决）〔2026-11-10〕
- 数值条一直显示满格位置或目标值（让观众知道要涨到多少）〔2026-10-30〕
- 角色出镜后数值条才出现、才变化（上の階 出镜前就加分被打回）〔2026-11-05〕
- 每次变化配数字滚动 + 放大/发光 + 音效，失望度、警戒度等往下降的数值条一样；变化时间点对准画面动作（原因待补）〔2026-10-30/11-05〕
- 数值条跟在角色头顶（或用户指定的位置），中心在头顶上方 200–280 px，且 y ≥ 250（贴头顶时脸凑近会被挡）〔2026-11-02〕
- 数值条尺寸：数字 100–120、标签 46–54、整体宽 600–680、条粗 20–24（用户验收）〔2026-11-02〕
- 「+N」出在数值条上方，普通 90–110、暴击 160–200，任何一帧都不出画（用户验收）〔2026-11-02〕

## 台词

- 每句台词一个重点词：放大 + 强调色 + 发光 + 弹入；只从原句里选，不加字；全量文案标了就照用，没标由包装选，随补充文案一起给用户确认（原因待补）〔2026-10-21〕
