# JP 日本

> 只写日本地区独有的做法。通用做法见 rules/通用.md；版式做法见 rules/B-剧情选择.md、rules/C-网感剪辑.md。

## 字体

- 日文只用带假名的字体，统一从 $RES/fonts 取（其他字体会掉成细体或缺字）〔日期待补〕
- 已验收字体：气泡 ZenMaruGothic-Black；标题、数值条、片尾 MochiyPopOne-Regular；内心独白 KleeOne-SemiBold；监控/HUD/识别文字 DotGothic16-Regular；微恐片尾 ZenOldMincho-Bold / -Black；简约高级风字幕和 UI 用 NotoSansJP-Bold / -Black，标题、数字、片尾大字用 ShipporiMinchoB1-ExtraBold（用户验收）〔2026-10-20/21〕
- 不用 YuGothB 做字幕、选项、片尾（用户：『字体太丑』）；不用 DelaGothicOne + ZenMaruGothic + 粉色描边的综艺风组合（用户：『廉价』）〔2026-10-20/21〕

## 标点和数字

- 按 rules/通用.md 去标点时，「。」「、」按句号逗号去掉（句中的换成空格或换行），「？」「！」和长音「〜」保留（〜 表达语气）〔2026-10-22〕
- 热度数字（聊天数、人数）可以用「万」，也可以写完整数字加千分位，配日语说法，例如「100万人がチャット中」「1,240,994」；不用「112.3万」这类中文写法（用户要日语本地化）〔2026-11-05〕

## 口播

- 送 TTS 的口播文本里产品名写成ミライマインド，屏幕字幕照文案写 MiraiMind（TTS 会把 MiraiMind 读错）〔2026-10-26〕

## BGM

- JP 纯甜恋爱的 BGM prompt 可写电钢琴、轻 pad 的甜系（八音盒在 rules/通用.md 的避开项里）（原因待补）〔2026-10-27〕

## 片尾

- JP 片尾默认用三卡片尾板 modules/endcard3（样式照 reference/投放参考/三卡片尾板_参考.webp：顶部 Logo → 三张角色卡扇形、中间本片角色金边高亮 + 名字 + チャット数胶囊、卡底聊天数持续跳涨 → 结尾卡文案末行金色大字 → 金橙渐变下载按钮），不再问用户；modules/jp-endcard 尾板模块只在用户点名要时用（用户裁决：「我要的三卡片尾板是这个…设为默认样式」）〔2026-11-12〕
- jp-endcard 尾板模块（用户点名才用）固定 17.3 s，不受自做片尾 ≤ 10 s 的限制；画面、文案、口播、时间轴都是验收定稿，要换就得重新配音、重新对时间，需另向用户申请（文案、口播、时间轴逐句对齐，改一处要全部重对）〔2026-10-27〕
- jp-endcard 自带的 BGM、音效是验收定稿，原样保留，不按『BGM 必须 ElevenLabs 生成』『音效用户优先』替换（用户裁决）〔2026-11-10〕；尾板闪避同样按 rules/通用.md 整句平滑压低，默认出片已是新混音，10-27 侧链版只在用户要时取（用户裁决：JP 尾板也不用侧链）〔2026-11-10〕
- 换角色时 hero 的 tag 和 chat 用全量文案；没写就由包装补写并给用户确认（日文附中文），用户不要就保持默认（用户裁决）〔2026-11-10〕
- JP 片尾不固定加免责声明（如「※本動画はイメージです」），用户要求时才加（用户裁决）〔2026-11-10〕
- 放进 timeline：endcard3 画成图层直接在 gen.py 里加，用法见 modules/endcard3/README.md；用 jp-endcard 时它出 mp4，mp4 和音频怎么接见 rules/工程交付.md「timeline」，参数见 modules/jp-endcard/README.md
