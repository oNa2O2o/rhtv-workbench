# 工程交付（目录、命名、拆片、图层、timeline、出片、自检、交付、多版本）

> 格式：做法（原因）〔日期〕。只写当前有效版本，修改经过记 CHANGELOG.md。用户当次要求优先于本文件。
> 流程顺序见 SKILL.md；画面、文案、声音规则见 rules/通用.md；变量和本机路径见 reference/环境.md。B、C 都按本文件做。

## 目录

- 用户给的素材目录就是工程目录 `$P`，所有产物都放在里面，不在别处建目录；用户没给就新建 `$WORK_ROOT/YYYY年M月D日MM-<地区>-<标题>`（原因待补）〔日期待补〕
- 全量文案固定叫 `$P/全量文案.md`（原因待补）〔日期待补〕
- 工程目录结构，B、C 统一用这一套（用户裁决：多版本同一工程内按 `_版本N` 分开）〔2026-11-10〕：
  ```
  $P/全量文案.md
  $P/素材/                     源视频（多版本 视频_1.mp4、视频_2.mp4…；低清放大版 <名>_1080.mp4）
  $P/工程素材/抽帧_版本N/        每个版本独立抽帧、联系表、核对图
  $P/脚本/                     gen.py、to_timeline.*、batch.sh（各版本共用）
  $P/包装素材_版本N/            该版本的图层 PNG、序列帧、audio/
  $P/包装素材_产品UI/           swipe_版本N.json、chat_版本N.json、产品UI-划卡_版本N.mp4
  $P/包装素材_尾板/             只有用 jp-endcard 时才有：MM-JP_尾板_定稿.mp4，或 _<配置哈希>.mp4 + 尾板配置.json
  $P/timeline_版本N.json
  $P/导出/                     校对预览
  $P/成品/                     验收后的成片（只放最新一版）
  $P/归档/旧版成品vN/            被替换的旧成品
  ```
  单版本片子也用 `版本1`（以后加版本不用改结构）。
- 单片配置、截图、脚本放工程目录，不放进 Skill；模块配置（swipe/chat/尾板配置）里的图片不写相对路径（模块从别的目录运行，相对路径会找不到）〔2026-11-09〕。各模块认哪些写法（app-ui 认 `$RES/` 前缀，jp-endcard 只认绝对路径）见模块 README
- 特效、字幕、贴纸都做成独立图层（PNG/序列帧）放进 timeline，不烘焙进底层视频（烘焙后改不了，猫娘返工过）〔2026-10-26〕

## 命名

- 工程名 = 工程目录名去掉日期前缀（如 `MM-JP-上の階のスポーツ女子`）（用户裁决）〔2026-11-10〕
- 校对预览：`导出/<工程名>_预览vN_<角色名>.mp4`，每改一轮 N+1（按轮次能找回上一版，也能看出改了几轮）〔2026-11-10〕
- 成品：`成品/<工程名>_<角色名>.mp4`（多版本靠角色名区分）〔2026-11-10〕
- 投放副本：复制到 `$UPLOAD_IN`，文件名按 xmp-upload 的命名规则，本 Skill 不另定（命名规则只维护一处）〔2026-11-10〕
- 多版本放在同一个工程里，按 `_版本N` 分目录/后缀（抽帧、图层、配置、timeline 都带版本号，防止串版本）〔2026-11-10〕

## 拆片

- 按 24 fps 抽帧到 `工程素材/抽帧_版本N/`，拼联系表看一遍，先写拆片笔记再定方案（不看全片就定方案容易错位）〔日期待补〕
- 源视频低于 1080p 时用 `scale=1080:1920:flags=lanczos,unsharp=5:5:0.6` 放大一份 `<名>_1080.mp4` 再用（用户接受过这个画质）〔2026-11-05〕
- ASR 用 `scripts/asr.py` 并指定语言（`--lang ja`，日语片用错成韩语模型过）：默认 ElevenLabs scribe（逐字，质量最好），失败自动转 whisper medium 并说明；whisper 是离线备选，按 energy.json 的能量段按句切（前后留 0.2–0.3 s），prompt 自动去掉「……」「——」，不用 large-v3、不降级到 small（large-v3 本机内存不够，small 会幻听）；再用 −35 dB 能量核对起止〔2026-11-05/11-12〕
- 取不到逐字时间时按能量切句，段内按假名数平均分（原因待补）〔2026-11-05〕

## 图层

- 图层一律是 1080×1920 透明整画布 PNG，元素画在最终位置，按用途拆成独立 PNG/clip（标题、字幕、底板…），动画用 timeline 关键帧（方便单独微调，不用重出图）〔2026-10-21〕
- 逐帧动画输出 `name_%03d.png`，用 sequence clip（原因待补）〔日期待补〕
- 重出图层可以沿用文件名，但旧图要清掉（render 不去重，残留旧图会混进画面）〔2026-11-09〕
- 生成前用 fontTools `getBestCmap()` 检查字体覆盖全部用字（缺字会显示成方块或掉成别的字体）〔2026-10-26〕

## timeline

- 格式以 `scripts/render.py` 文件头为准（格式说明只维护一处）〔2026-11-09〕
- 第一条 clip 是铺满全片的画面（底层不能空，见 rules/通用.md）〔2026-11-09〕
- 每段时间先吸附到 1/30 s 再累加（不然相邻片段会有半帧缝）〔2026-11-09〕
- 原声单独作为 audio，src、start、in、duration 和对应 video clip 一致（不一致会音画错位）〔2026-11-09〕
- 删掉某段原声（静音错误人声、去掉重复段）：把同源 audio 拆成两条，中间留空，video clip 不动〔2026-11-09〕
- 产品 UI、JP 尾板渲染出的 mp4 作为 video clip 放进 timeline，另加一条同 src 的 audio，start/duration 和 clip 一致（模块的音效、口播、BGM 都在这条里，漏了就没声音）〔2026-11-09〕
- 全屏特效层（故障色散、闪白、暗角）不跨出本段，不压到产品 UI/尾板上（病娇女教师复审抓到全屏特效层的叠放顺序问题）〔2026-11-12〕

## 出片

- 先 `render.py --still t1 t2 …` 在关键时间点出静帧，ffmpeg hstack 拼一张看版面；版面定了再出视频（静帧几秒就出，改版面最快）〔2026-11-09〕
- `render.py --draft` 出 540×960 校对预览，按「命名」放 `导出/`；验收后不带参数出 1080×1920 成片（draft 出得快）〔2026-11-09〕
- 每次改完就打开预览给用户看；只开图片和视频，脚本/json 不开目录，已开的目录不重复开（用 `scripts/open_dir.ps1`，只能在 Windows 用）（用户只看画面，开一堆目录是打扰）〔2026-10-27〕
- 没验收过的模块（如 app-ui chat）用之前先出静帧给用户确认（原因待补）〔2026-11-02〕

## 自检（交付前逐条过）

- ffprobe：1080×1920、H.264、yuv420p、有音轨（yuvj420p 用户打不开）〔2026-11-05〕
- ebur128 peak=true 测：响度约 −18 LUFS、真峰值 ≤ −1 dBTP；render.py 默认 limiter 0.84，全片渲染后自动打印 LUFS 和 dBTP，真峰值 > −1.0 以退出码 3 结束（--draft 只警告）（0.89 编码后真峰值 −0.4 dBTP 不合格；叠加后峰值曾到 +3 dB）〔2026-10-21/11-12〕
- blackdetect 查有没有意外黑屏（黑屏会被当成坏片，见 rules/通用.md）〔2026-11-09〕
- 关键时刻静帧拼图目视：字幕和文案一致（全量文案 + 已确认的补充文案）、卡片字段齐全不出界、数值变化和画面对齐、圆角没有锯齿〔2026-11-05〕
- 逐条核对原声、哔、音效、BGM、口播都在，BGM 全程无空档（交付过『哔没了』的片子；病娇女教师 BGM 空档到复审才发现）〔2026-10-22/11-12〕

## 交付

- 验收后必须出成片放进 `成品/`，用户没提醒也要做；没验收的只放 `导出/`（预览不能拿去投放，签售会未验收就进成品被指出过）〔2026-11-04〕
- `成品/` 只放最新一版，旧版移到 `归档/旧版成品vN/`（成品目录里有多版会传错）〔2026-11-04〕
- 交付后打开 `成品/`；需要投放时按「命名」复制到 `$UPLOAD_IN`（原因待补）〔2026-11-05〕
- 用户要求时才出无 BGM 版：`成品/<工程名>_<角色名>_无BGM版.mp4`，保留原声、音效和选项段悬疑 BGM，并告诉用户哪几段要避让（用户有时自己配 BGM）〔2026-11-10〕
- 交付说明写：成品路径和命名、本次装了哪些依赖、每条声音的来源和音量（原声/哔/音效/BGM/口播），最后写明「声音需要你听一下」（AI 听不了声音）〔2026-10-21〕

## 多版本（同台词换角色）

- 每个版本重做：抽帧、ASR 时间、黑场切点、定格帧、人脸跟踪、卡面/hero/背景帧、错误人声检查；设计、文案、口播、BGM、音效沿用（每个版本的视频时间和脸的位置都不一样，毒舌講座迭代串过版本）〔2026-11-05〕
- 先做 1 个版本给用户确认，再批量出（一次全出返工成本大）〔2026-10-21〕
- 做法：版本1 的 `脚本/gen.py` 只按规范时间（版本1 的时间）写，不给每个版本手填时间表；每个版本一个 `工程素材/抽帧_版本N/版本配置.json`（role、切点 A_END/B_IN/B_END、锚点 A1_MAP/A2_MAP、F1/F2/HERO 帧、subs 逐词时间，可选 BAR_POS/F1_UI_DY/F2_UI_DY），用环境变量 `VER=版本N` 切换；build() 最后用 `scripts/mmkit/timewarp.py`（`TimeWarp(cfg, canon).warp(…)`，配置里没有映射键时恒等）把整条 timeline 映射到本版本；逐词字幕用本版本时间、不映射；BGM 同源段保持相位：靠近结构切点的段锚在切点，其余沿用前一段的相位，段内不拉伸、不错相；定格帧 = 切点那一帧；`batch.sh 版本N [draft|final]` 一键出片示例见 `scripts/examples/`（同台词同运镜，各版本台词快慢差到 1.3 s，手填时间表会错位、BGM 交叉处会错相）〔2026-11-12〕
- 并行处理多个版本时，各版本的临时文件放各自目录（如 `工程素材/抽帧_版本N/_tmp/`），不共用同名临时文件（病娇女教师 v3 的代理覆盖过 v2 的临时脚本）〔2026-11-12〕
