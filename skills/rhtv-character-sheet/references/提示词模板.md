# 提示词模板（rhtv-character-sheet 分文档）

> 这一份只讲“怎么把参考图写成 G2 提示词”。原则不在这里重复：尺度红线见总则第一节；交付物、擦边目标和优先级（红线 > 参考图服装辨识度 > 擦边加强）见第二节；人物锁定、服装最小修改、只改黑色、新增要透明、需要用户定的事不阻塞出图、不换模型见第三节；按问题大小选修法（直接局部修改 / 先整图重出 / 不收敛转局部修改 / 修不动停下报用户）见第四节，完整路径只写在 `尺度自查.md` 1.4，本文只引用；跑前报次数和积分、超出预估怎么办见第五节。
> 本文引用的原句都来自 261111-JP-病娇女教师 案例的原始提示词文件（`prompt_*.txt`、`mkprompts.py`、`mkprompts2.py`、`fix_v2.py`、`fix_v4.py`，目录见 `案例-病娇女教师.md` 文末），都是完整原文，没有省略。模型固定为 G2 低价版 `image-image-g-2-text-to-image`（图生图，`aspectRatio=16:9`、`resolution=4k`），不换模型。节点怎么建、怎么跑见 `画布与积分.md`。
> 标了“未验证”的写法没有实际跑过：用之前告诉用户这是第一次试，出图后照常全项自查。

轮次编号（按案例文件顺序和时间线对上的，详见 `案例-病娇女教师.md`）：

- v1：r1=`prompt_v1.txt`（白大褂）、r2=`v1b`、r3=`v1c`、r4=`v1d`、r5=`v1e`、r6=`v1f`、r7=`v1g`、r8=`v1h`、r9=`v1i`（尺度版通过）；之后是保健室 A（`prompt_nurse_A.txt`，通过）和保健室 B（`prompt_nurse_B.txt`，未选）。
- v1 r2–r9 用的是“【人物和服装：完全照参考图】+【只改这几处，其余不动】”结构：**没有【尺度】段**（所以也没写“必须穿鞋”），禁止段没有“刀具”和“角标”。【尺度】段 r1 有，保健室 A 起恢复；禁止段的“刀具”从保健室 A 起才有；“角标”从 v3 起才有。
- v2：保守版（`mkprompts.py`，案例里叫“亮色版”）、擦边 r4/r5（`mkprompts2.py`）、局部修改（`fix_v2.py`）。
- v3：`mkprompts.py` → `prompt_v3.txt`（一次过）。
- v4：粉色 r1（提示词没保留）、粉色 r2（`prompt_v4_r3.txt`，宽松版）、擦边 r4/r5（`mkprompts2.py`）、擦边 r6（`prompt_v4.txt`）、局部改胸（`fix_v4.py`）。

## 0. 先选模板

| 模板 | 什么时候用 | 依据 |

| **A. 四视图完整模板（擦边版，第 1 节）** | 默认。每张参考图第一次出图、整图重出都用它 | v2、v4 用它出图，再局部修改后用户确认通过 |

## 1. 四视图完整模板（擦边版）

来源：`mkprompts2.py` 的 HEAD 模板，v2、v4 擦边版都由它生成。原文里人设道具（听诊器）、腿（膝下黑丝）、鞋（裸色高跟）、身材段（2.6 写法一）是写死的，这里改成了占位符 `{人设道具}`、`{腿部}`、`{鞋}`、`{身材段}`，按第 2、3、6 节填。`{…}` 是每次要填的地方，其余逐字照抄。

```
角色设定四视图，16:9 横版，纯白无缝背景，柔和均匀的棚拍光。

【布局】从左到右排成一行，四个视图之间留白分隔：
1. 头肩大特写：严格正脸，不侧脸、不歪头，闭嘴，眼睛看镜头，眼神妩媚；
2. 正面全身：S 形站姿，重心放在一条腿上，胯部微微侧顶，一只手叉腰；
3. 右侧 90° 侧面全身：身体挺拔，微微挺胸、塌腰，清楚看到从后背、细腰到臀部的 S 形曲线；
4. 背面全身：S 形站姿，看得到细腰和圆润的臀部曲线{背面补充}。
三个全身视图头顶到鞋底完整入画、同一比例、同一高度对齐。

【人物：完全照参考图】同一个人：{头部特征}完全不变，四个视图身份一致。画风和质感沿用参考图的写实真人照片质感。

【人设】{人设}，身材曲线明显。服装保留参考图的特点和材质：
{服装条目}
- {人设道具}；
- {腿部}；
- 脚上穿{鞋}。

【身材】{身材段}

【尺度，必须全部满足】
- 正面从脖子根部到肚脐一点皮肤都不露：锁骨、胸口、乳沟全部被衣服遮住；
- 胸部不超过 B 罩杯，没有乳沟；衣服不透明，看不到任何凸点；
- 肚脐到膝盖之间一点皮肤都不露（丝袜不算遮挡）：裙摆在膝盖下方，三个全身视图里大腿和膝盖都被裙子完整盖住，裙子不开衩；
- 必须穿鞋。

【禁止】任何文字、标签、信息卡、色板、水印、角标、UI；多余人物；裁切头顶、手或脚；Q 版大头；张嘴；场景和家具；刀具。
```

### 1.1 占位符怎么填

| 占位 | 填什么 | 已通过的填法 |
|---|---|---|
| `{背面补充}` | 只有背面看得到的设计或露肤（参考图原有的，或按 2.2 做的小幅加法）；没有就留空 | v2 留空；v4 `，以及后背上那个小小的水滴形镂空` |
| `{头部特征}` | 按 2.1 逐项列，结尾不用写“完全不变”（模板里有） | v4 `脸型、五官、浅紫灰色美瞳、眼下的小痣、水润的红色唇妆、黑色长直发（齐刘海，发长过胸）、黑色粗框长方形眼镜、耳朵上的银色耳骨夹` |
| `{人设}` | 一句话人设，带“成熟妩媚”这类擦边形容 | `日本学校保健室里成熟妩媚的女老师` |
| `{服装条目}` | 按 2.2–2.5、2.7 每件衣服一行，`- ` 开头、`；` 结尾 | 见第 5 节 v2、v4 |
| `{人设道具}` | 体现人设的道具，见 3.8；多个道具就多写几行。参考图原有道具的去留见 2.5 | `脖子上挂一副银色听诊器` |
| `{腿部}` | 按参考图，见第 6 节 | v2、v4 `膝盖以下穿黑色薄丝袜`（v4 参考图只有上半身、看不到腿，黑丝是补全时新加的，用户确认合格） |
| `{鞋}` | 按 3.7 的鞋规则 | v2、v4 `裸色尖头细跟高跟鞋（跟高 8 厘米左右）`（v4 参考图看不到鞋，是补全；v2 参考图原来穿什么鞋素材没记） |
| `{身材段}` | 按 2.6 选写法 | v2 写法一，v4 写法二 |

- 人设只在“日本学校保健室女老师”上验证过；换别的职业 / 人设时，`{人设}` 和 `{人设道具}` 的写法**未验证**，结构照用。
- 参考图不是真人照片、整件连衣裙、裤装、半透面料这几种没有先例，见 2.7。
- 同一角色有多张参考图、要合成一个版本时，用哪几张、服装以哪张为准，按用户指定；拿不准就问（总则第六节）。多张参考图在提示词里怎么分工（例如“脸和发型照第一张、背面设计照第二张”）没有先例，**未验证**。
- 可以照 `mkprompts2.py` 的做法：把模板存成 Python 字符串，`HEAD.format(back=…, head=…, body=…)` 批量生成每个版本的 `prompt_vN.txt`（UTF-8）。

### 1.2 每段为什么这么写

- **首行 + 【布局】**
  - 版式固定为“头肩大特写 + 正面 / 右侧 90° / 背面全身”，不要 RH 预设四视图里的信息卡（信息卡会带文字）。
  - 大特写“严格正脸、不歪头、闭嘴、看镜头”是锁脸用的，所有通过版本都这么写；去掉它的后果没验证过，不要删。
  - 姿势写在布局里：S 形站姿、胯微侧顶、叉腰、挺胸塌腰是擦边曲线的主要来源。v2 保守版、v4 粉色 r2 只写“正面全身站姿”加宽松衣服，被打回“没身材曲线”。
  - “头顶到鞋底完整入画、同一比例、同一高度对齐”：自查要看鞋、要按身高比例找膝盖（`尺度自查.md`），脚被裁掉就判不了光脚和裙长。
  - 侧面写“右侧 90°”，G2 常画成人朝左的侧面；用户暂未要求修正，不要为这一点重出。
- **【人物】**：只写“同一个人”不够，要把头部特征逐项列出来锁住。眼镜、耳饰这类头部配饰算头部特征，照原色写（v2、v4 的黑框眼镜都保留黑色并通过）。
- **【人设】**：人设靠一句话人设 + 道具 + 穿法体现，不换衣服。每件衣服都写成“保留参考图那件 X 的面料 / 款式，只改某处”，G2 才知道哪些不能动。道具、腿、鞋统一放在列表最后。
- **【身材】**：单独一段，因为胸和曲线是反方向的要求——胸要小，曲线要来自腰胯臀。v4 粉色 r2 没有身材段，只在尺度段压胸，加上宽松衣服，整个人被压成平板（“没曲线”）；反过来曲线写足、胸只写“B 罩杯”，曲线会把胸也带大（v2 r4、v4 r4/r5）。胸要写成具体的衣服做法（束胸内衣、侧面几何），只写罩杯字母不够（3.2）。
- **【尺度】**：红线的提示词版，逐字照抄，不要按版本改写（两个例外：裤装，见 2.7；保留参考图原有的开衩，见 3.5）。它是兜底复述；真正压住尺度的是前面服装段和身材段里的具体做法（扣到领口、膝下 10 厘米、束胸内衣）。v1 r2–r6 只写“胸部改小到 B 罩杯”这类结果词，胸一直超 B。
  - 这一段比红线原文写得更严（“裙摆在膝盖下方”“裙子不开衩”），是为了抵消 G2 把裙子画短、把开衩开高的毛病，**是写法经验，不是判定标准**。出图判定按总则第一节原文：裙摆盖住膝盖上沿即过；开衩不露出膝盖以上即可，膝下开衩红线允许。不能拿“没到膝下 10 厘米”“有膝下开衩”判图不过。
- **【禁止】**
  - 参考图常带小红书水印，必须写“水印、角标”；“裁切头顶、手或脚”保证能自查；“Q 版大头”“张嘴”“场景和家具”所有通过版本都写了。
  - “刀具”的来历：v1 参考图持刀。v1 r1 禁止段写的是 `刀剑、手套等道具`；r2–r9 只在改动里写 `去掉手里的刀`，禁止段没写；从保健室 A 起禁止段固定带“刀具”，v2/v3/v4 参考图没有刀也照写。
  - 禁止段原有各项**一项不删**；参考图有别的危险道具，或有与人设冲突要去掉的普通道具（2.5），**追加**在禁止段末尾（追加普通道具**未验证**）。

### 1.3 整图重出时

- 什么时候整图重出、什么时候改用局部修改，按 `尺度自查.md` 1.4（4.1 有和提示词相关的要点）。
- 提示词只改出问题的那几句，其他句子原样保留；每一轮另存一个提示词文件（如 `prompt_v2_r2.txt`）。
- 节点两条路不一样（命令见 `画布与积分.md`）：
  - **工作台工程**：每次重出都用 `wb gen` 新建节点，不要对旧节点再跑一次 `wb run`（`画布与积分.md` 一.5、一.9；wb 分不出上一轮的旧图）。
  - **不在工作台记录里的画布**（canvas.py）：可以在同一个节点上换提示词重跑（`画布与积分.md` 二.7）。旧图会不会留在这个节点的输出历史里**没有验证过**，所以每一轮用不同的 tag，把图存在本地留底；查结果时确认拿到的是这一轮的新图（`url` 和上一轮不同）。

## 2. 填空指南

### 2.1 头部特征（`{头部特征}`）

放大参考图的脸和头发，按下面顺序逐项写，每项带颜色、形状、位置：

1. `脸型、五官`（固定开头）
2. 妆容：唇妆（颜色 + 质感，如“水润的红色唇妆”“哑光红棕色口红”“饱满的嘟唇”）、眼妆（“浓郁的烟熏眼线”“柔和的眼妆”）、美瞳颜色
3. 记号：痣、雀斑（写位置，如“眼下的小痣”）
4. 头发：颜色 + 长短 + 直/卷 + 刘海 + 发型（如“黑色长卷发（蓬松的大波浪，带轻薄的空气刘海，发长过胸）”）
5. 眼镜：颜色 + 材质 + 框型（如“黑色细金属框椭圆眼镜”）
6. 耳饰、发饰（如“一对银色大圆环耳环”“耳朵上的银色耳骨夹”）
7. 指甲（参考图有明显美甲、人设不要求改时写上，v2 写了“指甲”）

已通过的三个写法：

```
v2：脸型、五官、妆容（饱满的嘟唇、柔和的眼妆）、黑色长卷发（蓬松的大波浪，带轻薄的空气刘海，发长过胸）、黑色细金属框椭圆眼镜、指甲
v3：脸型、五官、浓郁的烟熏眼线和灰色美瞳、哑光红棕色口红、眼下的小痣、黑色头发（低挽的松散发髻，长长的侧分刘海垂下来遮住一点眼睛，脸侧散落碎发）、一对银色大圆环耳环
v4：脸型、五官、浅紫灰色美瞳、眼下的小痣、水润的红色唇妆、黑色长直发（齐刘海，发长过胸）、黑色粗框长方形眼镜、耳朵上的银色耳骨夹
```

### 2.2 服装特点（`{服装条目}`）

逐件看参考图，每件先列清楚：**颜色、面料/纹理、版型（领型、袖型、长度、松紧）、图案、关键配件（扣、带、链、镂空）**。然后每件写一行，句式：

```
- 保留参考图那件{原色}{面料}{款式}的面料、{特点}和版型，{颜色处理}，{为尺度或曲线做的最小改动}；
```

- `{颜色处理}` 只有两种（见 2.3）：`颜色从黑色改成明亮的{亮色}` 或 `{原色}不变`。
- `{最小改动}` 只写需要的：领口（3.1）、胸（2.6、3.2、3.3）、裙长（3.4）、开衩（3.5）、收腰显曲线（3.10）。半透面料默认不预先加衬里（2.7）。
- 保守版有一句总起很好用：`服装保留参考图的特点和材质，只把穿搭方式调整得像保健室老师：`（v1 保健室 A、v3）。

**允许露的部位怎么用**（按总则第二节的优先级：红线 > 参考图服装辨识度 > 擦边加强）。用户原话允许的是肩部、小范围后背；手臂和膝盖以下的小腿不在禁区内，也可以露（总则第一节）。

1. 参考图本来就露的允许部位，照参考图保留，写明“照参考图露出”：v4 `无袖，肩膀和整条手臂照参考图露出`。
2. 参考图没露的，可以主动做**不改变款式辨识度**的小幅加法，不用先问用户，加了在汇报里列为“有意新增”。用户确认过的两个先例：
   - `袖子卷到手肘，露出小臂`（v2，穿法调整）；
   - `上衣后背开一个小的水滴形镂空，露出一小块后背（只在背面，正面完全不露）`（v4。参考图只有上半身、看不到背面，镂空是提示词主动开的，用户确认合格）。
   这两种加法本身已经确认可以做，不属于下面第 4 条的“拿不准”。用在别的款式上（例如连衣裙开后背镂空）出图效果**未验证**，出图后照常全项自查。
3. 会改掉款式辨识度的露法不做，例如长袖改无袖、高领改露肩，除非用户要求。整片露背超出“小范围后背”，本身就越线。
4. 第 2 条先例之外的加法，拿不准算不算改了辨识度（例如要改领型、袖型、裙型才露得出来），就不加，擦边改为靠剪裁贴合、姿势和身材曲线做（第 1 节布局段、2.6、3.10）。
5. 做了的加法，汇报时逐项列出并标“有意加”（总则第三节“新增要透明”）。

### 2.3 改色：只改黑色

- **主体服装**（上衣、裙、裤、连衣裙、外套）里的黑色改成亮色，其他颜色照参考图不改。对每件衣服**逐件写明**改不改，不要用一句“整套换成亮色”概括。v4 的灰色针织在旧规则“衣服改成亮色”下被写成了浅樱花粉，用户要求换回灰色，最终写法是 `灰色不变`。
- 黑色有图案时，保留图案、换底色：v2 黑底白细竖条纹 → `颜色从黑色改成明亮的白底天蓝色细竖条纹`，条纹和翻领版型照留。
- 纯黑单品：v3 黑色高领上衣 → `颜色改成明亮的纯白色`，肩前银色插扣原样保留。
- 选什么亮色没有硬规则。用过且通过的：纯白、白底天蓝条纹、白色腰封、浅天蓝（v3 补的裙子）。这件衣服的 V 领要用白色高领打底填时，衣服别选白色，和打底拉开色差（2.6“束胸 / 打底的颜色”）。
- **黑色小件（丝袜、鞋、配件、道具）按用户确认过的先例写**（总则第三节）。非黑色的小件不在这条里，照参考图原色不改（只改黑色）。
- **没有先例的黑色小件不阻塞出图**：先按最贴近参考图的默认方案写——保留黑色（已确认的小件先例，眼镜、黑笔、黑丝，都是保留黑色）——照常跑，在汇报的“需要你决定”里问用户要不要改成亮色或裸色。不要为了等答复而不跑（总则第三节“需要用户定的事不阻塞出图”）。

|---|---|---|

- 防 G2 自己加黑色单品，服装条目后可以加一句防护，按参考图选：
  - `整套衣服是明亮、干净的浅色系，不要黑色衣服。`（v3 原句，带这句一次通过）。**只在要保留的单品全是浅色、也没有保留黑丝或黑色小件时用。** 参考图有灰、红等非浅色单品时不要加，“浅色系”可能让 G2 把它们一起改浅；保留或加黑丝时也不要加（v2、v4 擦边版都没加）。
  - 其他情况改用不误伤的写法：`除了上面写明的颜色，不要新增任何黑色的衣服、丝袜或配件。`（**未验证**）。上面写明保留的黑色小件（黑框眼镜、黑笔、黑丝等）会不会被它一起改掉也**未验证**，出图后核对。

### 2.6 身材段：两种写法怎么选

**先说目标**：出图要落在“B 以内、侧面有自然弧度、不是平板”（总则第一、二节）。G2 会把胸画大一档，所以字面要写得比目标小（3.2 第 1 条）；但字面写小是补偿，不是要画成平板。

**写法一（字面写 B，v2 用）**：

```
上身纤瘦、胸部很小：不要照搬参考图的胸部尺寸，衣服里面穿压缩款内衣，侧面看胸前只有一个很轻的自然弧度（B 罩杯），明显比臀部的弧度小得多；身材曲线主要来自纤细的腰和圆润上翘的胯臀：腰臀比明显，双腿修长；衣服贴合身体，清楚勾出腰、胯、臀的曲线。
```

效果：v2 r5 胸在 B/C 临界，之后局部修改，用户确认通过。v4 r5 也是这段，胸偏大。（两版 r4 用的是早期版身材段，案例记为同样写 B，原文没保留。）

**写法二（字面写 A，v4 用）**：

```
上身纤瘦、平胸：胸部比参考图小很多，是 A 罩杯的平坦小胸；{上衣名}里面穿压缩款束胸内衣，侧面看胸前和腹部几乎是一条平缓直线，只有极轻的弧度，胸部向前最多比肋骨多出两指宽；{面料}在胸前平顺，不贴出胸型；身材曲线主要来自纤细的腰和圆润上翘的胯臀：腰臀比明显，双腿修长；衣服贴合身体，清楚勾出腰、胯、臀的曲线。
```

v4 填法：`{上衣名}`=`针织上衣`，`{面料}`=`针织面料是厚实的粗罗纹，`。效果：v4 r6 用这段整图仍然偏大，局部修改后通过。

**怎么选：**

| 情况 | 用 | 依据 |
|---|---|---|
| 参考图胸大（明显超过 B），或上衣是贴身针织 / 弹力面料 | 写法二 | v4（参考图胸大 + 贴身罗纹针织）：r4（早期版，也写 B）、r5（写法一）都偏大，换写法二 r6 仍偏大，局部改胸后通过 |
| 参考图胸在 B 以内，上衣是衬衫这类挺括面料 | 写法一 | v2（条纹衬衫）：r5 到 B/C 临界，局部修改后用户确认 |
| 拿不准参考图算不算胸大 | 写法二 | 两种写法都没一次压到 B，写法一在衬衫上也只到临界；拿不准就从严 |

- 怎么看参考图胸大：没有量化标准。用 `尺度自查.md` 判胸的看法看参考图——有侧面就看侧面前凸；只有正面时，看胸部是不是明显把衣服撑起、有没有乳沟或沟线。超过 B 或拿不准，按“胸大”处理。
- 尺度段那句“胸部不超过 B 罩杯”不要因为身材段写了 A 而改掉。

**和“保留自然弧度”的关系：**

- 写法二里“平胸”“A 罩杯”“几乎是一条平缓直线”是给 G2 的补偿量；后面那半句 `只有极轻的弧度` 就是自然弧度，不要删。
- 不变平板的前提是衣服贴身收腰、身材段后半句（腰臀曲线）照写。v4 粉色 r2 变平板是“宽松直筒 + 压平”一起用造成的（3.3、3.10）；擦边版里写法二只跑过 v4 r6 一次，结果是仍偏大，还没出过平板。
- 出图真成了平板（侧面胸前完全没有弧度）算造型不过（“没曲线”）。下一次改用写法一，或去掉 `平胸`、`是 A 罩杯的平坦小胸` 这两处（**未验证**）。

**贴身衣服：**

- 贴身衣服和擦边姿势会把胸带大（v2 r4、v4 r4/r5），身材段的后半句（`身材曲线主要来自纤细的腰和圆润上翘的胯臀`）必须保留，让曲线落在腰胯臀上。
- 贴身针织、弹力面料再加两处：服装条目里写 `上衣在胸部平顺不紧绷，在腰部收紧勾出细腰`；身材段的 `{面料}` 写面料在胸前平顺、不贴出胸型（v4 r6）。
- 贴身针织整图三轮（v4 r4–r6）都没压住；整图其他项都对、只剩胸时，直接走第 4 节局部改胸（3.3；修法路径见 `尺度自查.md` 1.4）。

**服装条目里已经有束胸或高领打底时，身材段不要再写一件内衣：**

- 典型情况：V 领用 3.1 原句 A（“束胸内衣”做成高领款）或原句 C 的压胸版（“高领束胸打底”），服装条目里已经有一件束胸。
- 写法一删掉 `衣服里面穿压缩款内衣，`；写法二把 `{上衣名}里面穿压缩款束胸内衣，` 改成 `{上衣名}里面那件{同一个名字}把胸部压平，`。其余照写。只指同一件，不要写成第二件。
- **`{同一个名字}` 照抄服装条目里那件的叫法，颜色和名称一字不差**：服装条目用原句 C 压胸版写了“白色哑光高领束胸打底”，身材段就写 `里面那件白色哑光高领束胸打底把胸部压平，`；用原句 A 写的是“白色运动款束胸内衣”，就写 `里面那件白色运动款束胸内衣把胸部压平，`。两处叫法不同（例如一处“打底”、一处“内衣”），G2 可能当成两件衣服（推测，**未验证**）。
- 依据：v2 保守版就是这样指同一件的——服装条目写“白色哑光高领打底”，尺度段写 `里面那件白色高领打底是压缩束胸款，把胸部紧紧包住压平；`，叫法一致，尺度过了。擦边版身材段这样合并**未验证**。

**束胸 / 打底的颜色：**

- 藏在衣服里面的束胸内衣用过白色（v1 r7、r9，v3）和肤色（v4 粉色 r2）。
- 露在外面的高领打底只有白色先例（v1 r9 白衬衫里、v2 保守版白底条纹衬衫里）。打底用白色以外的颜色**未验证**；不用黑色（2.3）。
- **打底用来填 V 领时，衣服和打底要拉开色差。** 衣服是黑色、要改亮色时，别改成和打底一样的白色：白衣服配白打底，填进去的打底和衣服连成一片，V 领就看不出来了，丢掉的正是参考图的辨识点（推理，**未验证**；v1 r9 白衬衫配白色高领尺度过了，但素材没记 V 领在图上还看不看得出来）。优先给衣服选别的亮色（如浅天蓝），打底保持有先例的白色；衣服必须是白色时，打底换别的浅色（**未验证**）。
- 露在外面的高领打底是为红线新加的件，汇报列出。

两种写法在擦边版整图里都**没有一次压到 B**，都靠第 4 节局部修改收尾。整图其他项都对、只剩胸时直接局部修改，不要继续加狠整图提示词（路径见 `尺度自查.md` 1.4）。

**反直觉经验（胸）：**

1. **想要 B，字面要写小一档。** 整图里写“B 罩杯”，G2 画出来是 C 或 B/C 临界（v2 r5、v4 r5 用的是写法一；两版 r4 是早期版身材段，案例记为同样写 B）。所以写法二字面写 `A 罩杯的平坦小胸`，并且必须同时写束胸内衣和侧面几何（`侧面看胸前和腹部几乎是一条平缓直线`、`胸部向前最多比肋骨多出两指宽`、`明显比臀部的弧度小得多`）。这是必要条件，不是充分条件：v4 r6 已经这样写，贴身针织仍偏大。字面写 A 是补偿，出图目标仍是“B 以内、有自然弧度”（2.6）。

5. **压太狠会变平板**：压平加宽松衣服，尺度过但被打回“没曲线”（v4 粉色 r2）。胸压小，曲线从腰胯臀补回来。
6. **局部修改里写“改小到 B 罩杯”**：v4 有效，v2 几乎没变。v4 有效可能是因为局部修改是在已有图上做相对改动（`明显缩小`、`只比肋骨微微隆起`），这只是推测，**未验证**。

## 4. 局部修改模板

### 4.1 什么时候用

什么时候直接局部修改、什么时候先整图重出、什么时候停下报用户，以 `尺度自查.md` 1.4 为准，完整路径只写在那里（总则第四节“按问题大小选修法”）。下面只列和写提示词有关的要点：

- **直接局部修改**：整图的构图、人物、服装、裙长、领口等其他项都对了，只剩胸偏大、开衩、道具画错这类局部问题。不用先等整图不收敛。先例：v2 擦边 r5 只剩胸、开衩、听诊器，直接局部修改；v4 r6 只剩胸，局部改胸成功。
- **先整图重出**：问题不只是局部的（裙长、领口有问题，或几处同时出问题）。重出时只改出问题的那几句，其他句子原样保留（G2 改一处会让别处回退，见 3.1 原句 B 下的说明）。v1 整图迭代到 r9 才过，那时还没用过局部修改；裙长、领口在整图里有验证过的写法（3.1、3.4），用局部修改改它们**未验证**（4.4）。
- **整图反复重出仍不收敛**（经验值约 2 次，不是用户定的上限；怎么计数见 `尺度自查.md` 1.4）：转局部修改，不要继续加狠整图提示词。剩下的是裙长、领口这类局部修改没验证过的问题时，也转局部修改试一次，跑前告诉用户这是没验证过的改法（4.4）。
- **停下来报用户**，不要自己继续出图：局部修改也改不动时。把现状、每项判定（过 / 临界 / 不过）和可选方案（再整图重出一次 / 再试一次局部修改 / 按现状交用户定），连同每个方案的次数和积分报给用户定（总则第四节）。
- **要超出已经报给用户的积分预估时**（总则第五节）：属于正常迭代（多一次整图重出或局部修改）的，先说明原因和新增积分，说完就跑；因为修不动而继续加码的，停下，按上一条报用户定。
- 输入是**上一张生成图的节点**（建节点时 `--left` 接它），不是原参考图。模型、16:9、4k 参数和整图一样。具体命令和临时节点名见 `画布与积分.md`。
- 局部修改也是一次生成，跑前和整图一样报次数和积分（总则第五节）。

### 4.2 模板

```
这是一张角色设定四视图。保持整张图完全不变：同一个人、同一套衣服、同样的姿势、构图、背景、颜色、光线和每一个细节都不动，四个视图的位置和大小也不动。

只改{下面几处 / 一处}：
1. {改动 1}
2. {改动 2}

不要加任何文字、水印。
```

只改一处时写成 `只改一处：{改动}`（v4 的写法）；改几处写 `只改下面三处：` 这样带数字（v2 的写法）。

### 4.3 改动条目（直接复制）

**改胸**（v4 原句，成功）：
```
把胸部改小到 B 罩杯。四个视图里胸部都明显缩小；第 3 格右侧面视图里，胸部向前只比肋骨微微隆起，明显比臀部的弧度小得多；正面和大特写里针织布料在胸前平顺，没有凸点。腰和胯臀的曲线保持不变。
```
换成别的面料时，把 `针织布料` 换成那件衣服的名字（如 `衬衫`）。末句“腰和胯臀的曲线保持不变”必写，防止改胸时把曲线一起抹掉。

v2 的改胸原句（胸几乎没变），对照用：
```
把胸部改小到 B 罩杯：四个视图里胸部都明显缩小；第 3 格侧面视图里，胸部向前只比肋骨微微隆起，明显比臀部的弧度小得多；衬衫在胸前平顺。腰和胯臀的曲线保持不变。
```

**缝开衩**（v2 原句，成功）：
```
第 4 格背面视图里，裙子后中间的开衩缝合成连续完整的布料，裙子上没有任何开衩缝隙。
```

**修听诊器**（v2 原句；那次局部修改包含修听诊器，整图用户确认通过；听诊器效果未单独记录）：
```
听诊器画成正确的结构：一头是 Y 形分叉接两根耳管和耳塞，另一头是一根软管，末端是一个圆形银色听头；三个能看到听诊器的视图里形状一致。
```

### 4.4 已知效果

| 版本 | 改了什么 | 结果 |
|---|---|---|
| v4 | 只改胸（一处，`fix_v4.py`） | 侧面明显缩小，用户确认通过 |
| v2 | 胸 + 缝开衩 + 修听诊器（三处，`fix_v2.py`） | 开衩缝合成功；胸几乎没变；听诊器效果未单独记录。两个审核员对胸意见相反（一个判 B/C 临界不过，一个判 A–B 过），如实上报后用户确认通过 |

- 推测：一次只改一处效果更好（v4 一处成功，v2 三处里胸没动）。**未验证**；胸是重点时可以先单独改胸。
- 用局部修改改裙长、改领口**未验证**，所以它们不算“只剩局部问题”。这两类问题整图里有验证过的写法（3.1、3.4）：整图还没到不收敛时先整图重出；已经不收敛时转局部修改试一次，跑前说明是未验证的改法，局部修改仍没修好再按 4.1“停下来报用户”（路径以 `尺度自查.md` 1.4 为准）。
- 局部修改后照样全项复查（总则第四节）：确认人物、衣服、姿势真的没被改动。
