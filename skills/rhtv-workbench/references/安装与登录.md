# rhTV 客户端安装与登录

工作台通过官方 rhTV 客户端（rhtvcli）读写画布。每台电脑装一次。

## 安装

1. 拿到官方安装包 `rhtv-canvas-clients-<版本>.zip`（团队共享盘或 RunningHub 官方渠道）。
2. Windows（PowerShell）：
   ```powershell
   $zip = '<安装包路径>\rhtv-canvas-clients-0.7.1-build-11.zip'
   $Rel = Join-Path $env:USERPROFILE 'rhtv-release\0.7.1-build-11'
   New-Item -ItemType Directory -Force $Rel | Out-Null
   Expand-Archive -LiteralPath $zip -DestinationPath $Rel -Force
   $boot = Get-ChildItem $Rel -Filter 'rhtv-bootstrap-*.zip' | Select-Object -First 1
   Expand-Archive -LiteralPath $boot.FullName -DestinationPath $Rel -Force
   Expand-Archive -LiteralPath (Join-Path $Rel 'rhtv-mcp-0.7.1.zip') -DestinationPath $Rel -Force
   $bootDir = (Get-ChildItem $Rel -Directory -Filter 'rhtv-bootstrap-*').FullName
   powershell -NoProfile -ExecutionPolicy Bypass -File (Join-Path $bootDir 'install.ps1') (Join-Path $Rel 'rhtv-mcp-0.7.1') install
   ```
   装好后命令在 `%USERPROFILE%\.runninghub-canvas\bin\rhtvcli.cmd`。`wb.py` 会自己找到它，不需要加 PATH。
3. 执行策略报错时，当前用户的 PowerShell 执行策略需为 RemoteSigned（让用户自己改）。

## 登录

```
%USERPROFILE%\.runninghub-canvas\bin\rhtvcli.cmd login
```

浏览器会打开授权页，**用户自己**确认账号并点批准（Agent 不代填账号密码）。之后：

```
%USERPROFILE%\.runninghub-canvas\bin\rhtvcli.cmd account
```

看到 `canvas:read / canvas:edit / canvas:create / canvas:run` 就可以了。连续 7 天不用才会过期，用一次自动续期。
