# 实扣积分对账

账本和画布名里的积分先按 rhtvcli 报价记；报价为 0、不完整或按实际用量计费（如 Seedance 母版）时画布名带 `+`。**实扣以 RunningHub 账单为准**。不让用户去查账单、报数字；拿不到就说缺什么（例如「123 浏览器里没登录 RunningHub」）。

## 对什么

- 账单网页：https://www.runninghub.cn/bill-task ；接口 `POST https://www.runninghub.cn/uc/point/consumeList`，body `{"current":1,"size":100}`。
- 返回 `data.records[]`：`bizNo` = rhtvcli 运行结果里的 `jobId`（不是 Canvas 的 taskId），`pointUsedPoint` = 实扣积分。
- wb 账本每笔运行记 `jobId`：`wb run` 跑完时记；`run --no-wait` 的在 `wb wait` / `wb adopt` 时补记。

## 拿账单（只读）

网页登录态在用户日常登录 RunningHub 的浏览器里：本机是 **123 浏览器**（`%LOCALAPPDATA%\123browser\User Data`）。内置浏览器和 Claude 用的 Chrome 都没登录；rhtvcli 只有画布权限，也查不到账单。

1. 只复制 `User Data\Local State` 和 `User Data\Default\Local Storage\leveldb` 到临时目录（保持 `<临时>\Local State`、`<临时>\Default\Local Storage\leveldb` 的结构）。其余都不碰：不复制 Cookies，不退出用户的浏览器，不改任何设置（123 浏览器不能开第二个实例）。
2. 用临时目录取登录态调接口，存成 `账单.json`：
   ```python
   from playwright.sync_api import sync_playwright
   hdr = {}
   with sync_playwright() as p:
       ctx = p.chromium.launch_persistent_context(TMP, channel="chrome", headless=True)
       pg = ctx.new_page()
       pg.on("request", lambda r: "/uc/point/summary" in r.url and not hdr and hdr.update(r.headers))
       pg.goto("https://www.runninghub.cn/user-center", wait_until="networkidle", timeout=90000)
       h = {k: v for k, v in hdr.items() if not k.startswith(":") and k.lower() not in ("content-length", "cookie", "host")}
       txt = pg.evaluate("""async ([u, h, b]) => (await fetch(u, {method: 'POST', credentials: 'include',
           headers: Object.assign({'content-type': 'application/json'}, h), body: JSON.stringify(b)})).text()""",
           ["https://www.runninghub.cn/uc/point/consumeList", h, {"current": 1, "size": 100}])
       ctx.close()
   open("账单.json", "w", encoding="utf-8").write(txt)
   ```
3. 用完立刻删掉临时目录副本。

## 填进账本

```
wb cost --reconcile 账单.json [--name <工程>]
```

- 按 bizNo 对上账本里运行的 jobId，把这笔积分改成实扣（原报价留在 `quoted`），同步工程积分和画布名；全部核对过就清掉画布名末尾的 `+`。已核对的不会重复加。
- `unmatched` 列出对不上的：「账本没记 jobId」或「账单里没有 bizNo」（一页 100 条不够就把 `current` 翻页再对）。这几笔还是报价数；确实对不上的才 `wb cost --name <工程> --add <差额积分> --settled --note "<依据>"` 手补。
