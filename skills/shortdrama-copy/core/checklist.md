# 交付前自检清单

**用法：**
- 大纲阶段查 A、B 两部分；写全文时查 A、B、C 三部分。
- 每一条都要过，回复末尾附【自检结果】。
- 有任何一条是 ❌，先改完再交付，不把"建议删或换"留给用户。

---

## A. 读取与路由

- [ ] 第一条回复最前面输出了【已读确认】表，路由表里的每个必读文件都有口令？
- [ ] 口令是从文件最后一行读到的原文，不是猜的？
- [ ] 题材路由选对了？（角色主动 → push-pull；病娇 → genres/yandere；等待回复 → waiting-preset；写全文 → languages/{lang}/）
- [ ] 动笔前写明了结构类型、幕数与时长、数值名与曲线？

## B. 剧情与结构（大纲和全文都查）

**体量和画面**
- [ ] 每幕约 10 秒，台词默认 2 句、上限 3 句？功能句（道歉、客套、赶人）改成了动作？
- [ ] 场景 ≤2 个？换场景的地方有转场字？
- [ ] 没有需要道具交互的动作？武器没碰到主视角？处境用画外音或环境声交代？
- [ ] 调研素材压缩过？（每幕 1 个行为 + 1 个句式，道具型行为改成画外音或角色动作）

**数值**
- [ ] 只设一个数值，名字贴合角色处境（不默认用好感度），全片不改名？
- [ ] 单次变化 30–50？每次变化都标出触发的选项、台词或画面事件？
- [ ] 出现外部威胁时数值反弹了一次？上升型数值结尾停在 99？

**选项**
- [ ] 每幕最后一句把话抛给主视角？不看提问只看末句也能懂选项？
- [ ] 选项写成主视角的回答原话（行动类选项写动词原形）？
- [ ] 标出了选中项，并且和下一幕画面接得上？最后一题不点选？
- [ ] 选项里提到的东西前面画面里出现过，叫法统一？
- [ ] 台词和选项里点名的服装、道具（如「白衣を掴む」）各个造型都成立？不成立的在全量文案里标出来，让 03 人设图照着做？

**剧情推进**
- [ ] 情绪有起有落，最后一幕是情绪最高点？
- [ ] 每一幕关系或真相都有实质变化？
- [ ] 角色态度的每次变化都有画面事件当动机？陌生 / 敌对关系没有凭空给好感？
- [ ] 最后一幕的真心话在嘴硬否认时说漏，说到一半被打断？
- [ ] 前面的台词或动作在后面回收成伏笔？
- [ ] 嘴上拒绝的东西，后面安排主视角撞见她偷偷接受？（适用时）
- [ ] 开场第一句有信息或笑点？开场字没有复述画面？
- [ ] 口癖、自称、称呼全片统一？
- [ ] 表演指示的表情幅度符合人设？（高傲、冷淡型用克制小动作）
- [ ] 台词像真人说的话，没有书面腔和刻意修辞？
- [ ] 没有加用户没要的元素？

**标题和屏幕文字**
- [ ] 标题给了 3–5 个网感短句候选并标出推荐？
- [ ] 结尾卡是「表面 → 真相」短句或抛问观众的短问句 + 下载引导？
- [ ] 卡片标题是人设关键词，没剧透身份？

**合规**
- [ ] 「前任」「女友」类称呼已替换？敏感动词用 ◯◯（至少两个圆圈）？
- [ ] 产品名写 MiraiMind，没有缩写成 MM？

## C. 本地化（写全文时查）

- [ ] 台词长度：韩语 / 日语每句 ≤20 字中文，英语每句 ≤15 词？
- [ ] 语法和语气符合母语者习惯？（日语敬体 / 常体和语尾、韩语敬语 / 半语、英语语气层级）
- [ ] 文化差异替换到位？（称谓、俚语、禁忌词）
- [ ] 用户给的原文 / 参考台词已校语法和错字，改动处标出？
- [ ] 表格格式：目标语言栏的表演指示留空，幕标题只保留数值？
- [ ] 下载引导用目标语言的标准写法？口播的产品名标了配音读音？

---

## 输出格式

```
【自检结果】
- A 读取与路由：✅
- B 剧情与结构：✅（改过：第二幕数值 −60 → 拆成 −30 / −30）
- C 本地化：✅ / 本阶段不适用
```

括号里写这一轮自检中发现并已改掉的问题；没有就不写。
