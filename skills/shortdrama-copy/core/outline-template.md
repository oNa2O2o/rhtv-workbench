# 大纲模板（写全文前必出）

写全文前先给用户 **5 个剧情大纲** 选方向（SKILL.md §6）。本文件规定大纲长什么样。

---

## 硬规则在大纲阶段同样适用

大纲不是松散的故事梗概，而是全文的骨架。下面这些规则在大纲里就要满足，不能留到全文再改：

- 每幕约 10 秒，台词默认 2 句（上限 3 句），台词写成真人说的原话
- 场景 ≤2 个，换场景加转场字；不写需要道具交互的动作
- 只设一个数值，单次变化 30–50，每次变化标出触发点（选项 / 台词 / 画面事件），出现外部威胁时反弹一次，上升型停在 99
- 每幕最后一句抛给主视角，选项写成主视角的回答原话，标出选中项；最后一题不点选，直接进结尾卡
- 最后一幕是情绪最高点：真心话在嘴硬否认时说漏，说到一半被打断
- 前面的台词或动作在后面回收成伏笔
- 开场第一句就有信息；开场字只写画面演不出来的设定
- 违规词（前任 / 女友类称呼）不出现；敏感动词用 ◯◯

题材有专门参考时（如病娇 → `references/genres/yandere.md`），先按那里的压缩规则把调研素材压成一幕一个行为 + 一句台词。

---

## 每个大纲的格式

```
### X 《片名》｜人设一句话
- 数值：数值名 起点 → … → 终点（每个数字都能在下面找到触发点）
- 开场字（可选）：只写画面演不出来的设定或规则
- 第一幕：场景（数值名 起点）
  - 【表演指示】动作 → 动作（数值 ±N）→ 动作
  - 台词 1（有信息）
  - 台词 2（抛给主视角）
  - 选项：① 回答原话（选中，数值 ±N）② 回答原话 ③ 回答原话
- 转场字（换场景时才有）
- 第二幕：场景（数值名 a → b → c）
  - 【表演指示】动作（数值 ±N）→ 画外音 / 外部威胁（数值 ±N）→ 动作
  - 台词 1（嘴硬）
  - 台词 2（说漏，说到一半被打断）
  - 选项：① 回答原话 ② 回答原话（不点选，直接进结尾卡）
- 伏笔回收：第 X 幕的什么 → 第 Y 幕变成什么
- 标题候选：3 个网感短句（见 core/title-endcard.md）
- 结尾卡：「表面 → 真相」短句，或抛问观众的短问句
- 卡片标题：人设关键词，不剧透身份
```

三幕版在第一幕和最后一幕之间加一幕，选项 3 个，规则不变。

---

## 交付方式

1. 5 个大纲各自独立、方向不同（结构类型、人设或触发事件至少有一项不同）。
2. 末尾推荐 1–2 个，每个一句理由。
3. 回复末尾附【自检结果】（`core/checklist.md` 的 A、B 两部分）。
4. 大纲阶段只写中文；用户选定方向后再按目标语言写对照全文。

## 示例：A《第四声》（病娇 · 出轨审判型，大纲阶段合格稿）

### A 《第四声》｜同居的青梅竹马

- **数值**：理智度 100 → 60 → 90 → 40
- **开场字**：她只有一条规矩：电话三声之内接
- **第一幕：玄关（理智度 100）**
  - 【表演指示】画外手机铃响到第四声停下 → 她握着手机站在门口，笑着凑近你的衣领闻了一下（理智度 −40），笑容停住
  - 第四声才接呢
  - ……这个香水，是谁的？
  - 选项：① 同事的（选中）② 你闻错了 ③ 新买的
- **第二幕：同一个玄关（理智度 60 → 90 → 40）**
  - 【表演指示】她松了口气，退后半步笑了（理智度 +30）→ 画外你口袋里的手机响了一声、两声（外部威胁，理智度 −50）→ 她拽住你的袖口，盯着你的口袋
  - 我才不介意你跟谁吃饭呢
  - 我只是想把你……（第三声铃响，打断）
  - 选项：① 接电话 ② 挂掉（不点选，直接进结尾卡）
- **伏笔回收**：开场的"三声规矩"，到第二幕变成正在响的第三声。
- **标题候选**：第四声，她就知道了 / 晚接一声电话的代价 / 她闻到了别人的香水
- **结尾卡**：电话还在响，你接还是不接？
- **卡片标题**：同居的青梅竹马

**为什么合格：**
- 两幕都在同一个玄关，没有道具交互；电话只用铃声交代
- 理智度每次变化都有触发点：闻衣领 −40、回答后放松 +30、第三方来电 −50（外部威胁反弹）
- 第一幕末句「这个香水，是谁的？」抛给主视角，选项就是回答原话
- 第二幕嘴硬（「我才不介意」）→ 说漏（「我只是想把你」）→ 被第三声铃响打断
- 开场字的规则在结尾被回收
