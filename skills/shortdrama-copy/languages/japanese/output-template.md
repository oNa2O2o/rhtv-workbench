# 日语输出模板

日中对照表格的标准输出格式。

---

## 标准表格结构

```markdown
| 中文 | 日语 |
|---|---|
| **标题** | **タイトル** |
| 网感短句标题（见 core/title-endcard.md） | 日语标题 |
| **第一幕：幕名（数值名：数字）** | **数值名：数字** |
| **【表演指示】**<br>（角色+表情，角色+语气，角色的手/部位+动作；动作触发的数值变化括注在动作后） | <br> |
| 中文台词（默认2句，末句抛给主视角） | 日语台词 |
| ① 选项A（选中）<br>② 选项B<br>③ 选项C | ① 日语A<br>② 日语B<br>③ 日语C |
| **第二幕：幕名（数值名：数字）** | **数值名：数字** |
| **【表演指示】**<br>（角色+表情，角色+语气，角色的手/部位+动作） | <br> |
| 中文台词 | 日语台词 |
| ① 选项A<br>② 选项B（最后一题可不点选） | ① 日语A<br>② 日语B |
| **第三幕（可选）：幕名（数值名：数字）** | **数值名：数字** |
| **【表演指示】**<br>（角色+表情，角色+语气，角色的手/部位+动作） | <br> |
| 中文台词 | 日语台词 |
| ① 选项A<br>② 选项B | ① 日语A<br>② 日语B |
| **结尾卡文案** | **エンディングカード** |
| 「表面→真相」短句或抛问观众的短问句<br>点击下载浏览后续 | 日语短句<br>ダウンロードして続きを見る |
| **卡片标题** | **カードタイトル** |
| 人设关键词（不加动词、不剧透身份） | 日语人设关键词 |
| **屏幕文字** | **屏幕文字（日语）** |
| 开场字 / 转场字 / 按钮 | 逐条本地化 |
```

不写【UI提问】行：前一幕最后一句已经把话抛给主视角。只有用户明确要求加提问时才写，日语栏用 `【UI質問】` 标记。

---

## 格式说明

### 标题行

默认写网感信息流短句，规则和候选写法见 `core/title-endcard.md`，先给 3–5 个候选让用户选。

**示例：**
```
| 交不起房租是你的谎言 | 家賃が払えないなんて、嘘だろ |
```

「在MiraiMind中 + 核心动作」是 v2.0 旧写法，只在用户明确要求时使用，如 `| 在MiraiMind中惩罚洁癖女囚犯 | MiraiMindで潔癖症の女囚を罰する |`。

---

### 幕标题行

**中文栏：**
```
第一幕：幕名（数值名：数字）
```

**日语栏：**
```
数值名：数字
```

**示例：**
```
| **第一幕：初次交锋（好感度：-20）** | **好感度：-20** |
```

**注意：**
- 日语栏只保留数值，不保留幕名
- 数值名称需要翻译成日语

---

### 表演指示行

**中文栏：**
```
【表演指示】
（角色+表情，角色+语气，角色的手/部位+动作）
```

**日语栏：**
```
（留空，只需换行符）
```

**示例：**
```
| **【表演指示】**<br>（角色右手抓住主视角的左手腕，向前拉拽） | <br> |
```

**注意：**
- 日语栏必须留空
- 使用 `<br>` 换行，保持表格对齐

---

### 台词行

**中文栏：**
```
中文台词
```

**日语栏：**
```
日语台词
```

**示例：**
```
| 你这个变态狱警，想对我做什么？ | 変態刑務官、あたしに何するつもり? |
```

**注意：**
- 中文台词是日语的对照翻译，不能省略
- 日语台词必须符合本地化规则
- 注意敬体/常体选择
- 注意性别语尾

---

### UI提问行（默认不写）

默认不写【UI提问】：每幕最后一句台词已经把话抛给主视角，选项就是主视角的回答。

只有用户明确要求加提问时才写，日语栏用 `【UI質問】` 标记，格式如下：
```
| **【UI提问】** 这个囚犯挑衅你这个新来的狱警，怎么做？ | **【UI質問】** この囚人が新人刑務官のあなたを挑発している。どうする? |
```

---

### 选项行

**中文栏：**
```
① 选项A
② 选项B
③ 选项C
```

**日语栏：**
```
① 日语A
② 日语B
③ 日语C
```

**示例：**
```
| ① ◯◯她<br>② 殴打她<br>③ 禁止她洗澡 | ① ◯◯する<br>② 殴る<br>③ シャワーを禁止する |
```

**注意：**
- 选项是一个行动时，只保留动词原形；选项在回答角色的台词时，写主视角说出口的原话
- 被点中的选项标「（选中）」，必须和下一幕画面接得上；最后一题可以不点选
- 敏感词用 ◯◯ 和谐

---

### 结尾卡文案

两行：一句「表面→真相」短句（或抛问观众的短问句）+ 下载引导。不写剧情陈述长句，详见 `core/title-endcard.md`。

**示例：**
```
| **结尾卡文案** | **エンディングカード** |
| 房租只是借口，你才是她想要的<br>点击下载浏览后续 | 家賃は口実。欲しかったのは、あなた<br>ダウンロードして続きを見る |
```

---

### 卡片标题

直接写人设关键词，不加动词，不剧透剧中要揭晓的身份。

**示例：**
```
| **卡片标题** | **カードタイトル** |
| 未亡人雪女 | 未亡人雪女 |
```

---

## 完整案例

> ⚠️ 下面的完整案例是 v2.0 旧结构（每幕写【UI提问】、「在MiraiMind中」标题、数值一幕跳 100、结尾卡写剧情陈述、卡片标题带动词），**只用来参考日语语气和本地化写法，结构不要照抄**。当前结构以 SKILL.md「默认输出模板」和 `references/japanese/gold-dialogues.md` 的成品案例为准。

### 驯化结构案例

## 格式检查清单

输出前检查：

```
□ 标题是网感短句（不默认套「在MiraiMind中」）？
□ 幕标题中文栏是否包含数值？
□ 幕标题日语栏是否只保留数值（不含幕名）？
□ 表演指示日语栏是否留空？
□ 没有多余的【UI提问】行？（用户要求写时，日语栏用【UI質問】标记）
□ 结尾卡是短句 + 下载引导？卡片标题是人设关键词、没剧透身份？
□ 下载引导日语是否用"ダウンロードして続きを見る"？
□ 敬体/常体使用是否一致？
□ 女性/男性语尾是否正确？
□ 表格对齐是否正确？
```

## 注意事项

### 敬体/常体一致性

同一角色在同一剧情中必须保持敬体或常体一致，除非关系发生明确变化。

**错误示例：**
```
❌ 第一幕：好きです（敬体）
   第三幕：好きだ（常体）← 没有关系变化
```

**正确示例：**
```
✅ 全程用敬体：好きです → まだ好きです → ずっと好きです
✅ 或在第二幕明确转换：好きです → 好きになった（关系变亲密）
```

### 性别语尾正确性

女性和男性的语尾不能混用。

**错误示例：**
```
❌ 女性角色：知ってるぜ（男性语尾）
❌ 男性角色：知ってるわよ（女性语尾）
```

**正确示例：**
```
✅ 女性角色：知ってるわよ
✅ 男性角色：知ってるぜ
```

### 人称代词性别正确性

**错误示例：**
```
❌ 女性角色：俺は知らない（男性自称）
❌ 男性角色：あたしは好き（女性自称）
```

**正确示例：**
```
✅ 女性角色：あたしは知らない
✅ 男性角色：俺は好きだ
```
