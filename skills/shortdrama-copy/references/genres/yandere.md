# 题材参考：病娇（ヤンデレ）

写病娇、占有欲强、跟踪/监禁类危险角色时必读。和 `core/push-pull-structure.md` 一起用：角色主导，主视角被动。

---

## 1. 来源和定位

- 提炼自「MM-JP 男性向音声 · 全量文案」里 377 部病娇及相关标签作品（按播放量精读前 240 部的完整台词，全部 377 部做了关键词统计）。
- 这些音声是 **5–10 分钟的长篇第二人称独白**，买量素材一幕只有约 **10 秒、2 句台词**。
- 所以本文件只能**取用、压缩**，不能照搬：长音声里一整段的审问、下药、监禁过程，在素材里只能剩一个动作加一句话。

---

## 2. 压缩规则（最关键）

1. **每幕只取 1 个行为 + 1 个句式**。行为见第 4 节，句式见第 3 节。
2. **行为按下表分三档处理**，不确定的一律降一档：

| 档位 | 处理方式 | 例子 |
|---|---|---|
| 可以直接拍 | 写进【表演指示】，动作集中在角色本人 | 凑近闻衣领、笑容停住、攥紧袖口、背靠门、指尖搭在门把上、视线落在主视角口袋上、竖瞳一闪（人外） |
| 改用画外音 / 环境声 | 声音交代，不让角色解释 | 手机铃声（响几声）、敲门声、第三者的女声、门锁"咔"一声、管家通报、新闻播报 |
| 不写 | 只能用结果暗示，或者放进结尾卡留白 | 下药过程、查看手机屏幕内容、上手铐/锁链的操作、刀和武器碰到主视角、殴打掐脖、血腥、自残 |

3. **监禁只写到"出不去"的暗示**：门锁声、她背靠着门、"门是顺手锁的"。不写绑起来、关进房间的过程。
4. **武器只做警告动作**：菜刀拿在身侧、切菜声停住，不指向、不碰主视角（见 SKILL.md §7）。
5. **涉及性的内容停在擦边之前**（见 `core/push-pull-structure.md`）。

---

## 3. 台词句式库

长音声原句往往很长，素材里要压到 ≤20 字。每种句式给出"素材写法"和"原作例句"（原作例句只用来理解语感，不直接抄）。

| 句式 | 作用 | 素材写法（短） | 原作例句 |
|---|---|---|---|
| 温柔包着威胁 | 分不清她是温柔还是危险，病娇感的核心 | 「没事的。只要你不走，我就一直温柔哦」 | 「只要你别背叛我，我就会一直是温柔的我哦。」 |
| 复述再反问 | 主视角不出声，靠她复述交代主视角说了什么；常是情绪转折点 | 「"同事而已"？」 | 「"想要自由"？……所以说，这不就是自由吗」 |
| 宣布既成事实 | 取消主视角拒绝的权利 | 「已经不是来，是待着哦」 | 「拒绝权嘛，有倒是有，但不许用哦」 |
| 甩锅 / 说成为你好 | 把控制合理化 | 「是你让我变成这样的哦？」 | 「才不是呢。这叫保护。」 |
| 狠话后撤回 | 撤回本身也是施压 | 「……开玩笑的啦」 | 「甚至想挖出来好好端详一番呢。开玩笑的啦。」 |
| 一句话变冷 | 黑化开关 | 「这样啊。」/「……是谁的？」 | 「旁边那个女人……是谁？」 |
| 嘴硬时说漏 | 对应 SKILL.md §9「真心话在嘴硬否认时说漏、说到一半被打断」 | 「我才不介意……我只是想把你——」 | （原作多为直接宣告，素材里改成说漏） |

**口吻要求：**
- 句尾常带轻笑、反问；温柔的语气说可怕的内容，不要吼。
- 称呼和自称**全片统一**（SKILL.md 硬规则）。长音声里常见"黑化时换称呼"，素材 20 秒里不换，黑化靠语气骤冷表现。
- 高频口头词可选用：「呐」「对吧？」「乖」「一直」「只属于我」，一幕最多用一个，不要堆。

## 5. 结构映射

### 默认结构：两幕，危险角色主导

| | 第一幕（约 10s） | 第二幕（约 10s，情绪最高点） |
|---|---|---|
| 作用 | 甜/温柔的表面 + 第一个异常 | 假装放松（数值反向）→ 外部威胁 → 说漏 |
| 台词 | 第 1 句有信息；第 2 句抛给主视角 | 第 1 句嘴硬；第 2 句说漏，说到一半被打断 |
| 选项 | 3 个，标出选中项 | 2 个，不点选，直接进结尾卡 |

三幕版：在两幕中间插一幕"她试探 / 主视角想走"，其余不变。

### 数值

- 只设一个数值，名字贴合病娇处境，不用好感度：
  - 下降型：**理智度、克制度**（越低越危险）
  - 上升型：**独占欲、占有欲、执着度**（结尾停在 99）
- 单次变化 30–50，每次变化都标出触发点（选项 / 台词 / 画面事件）。
- **反弹**：第二幕先让数值往"安全"方向回一次（主视角的回答让她放心、她假装放手），再由**外部威胁**拉回最危险。
- **外部威胁统一用第三者的画外音**：手机铃声、女声、敲门声、管家通报。

### 常见触发和节拍

原作里黑化的触发大约三分：接近别的女性/被认定出轨（约 1/3）、主视角要离开（分手、拒绝、辞职、逃走，约 1/3）、主视角没做错是她早有预谋（约 1/4）。对应到素材：

| 节拍 | 第一幕 | 第二幕 | 适合的人设 |
|---|---|---|---|
| 出轨审判 | 迎接 → 发现痕迹（香水味、画外女声）→ 质问 | 回答让她放心 → 画外第三者再出现 → 说漏 | 同居青梅竹马、黏人后辈 |
| 温柔陷阱 | 收留 / 醒来 / 报恩 → 问主视角去留 | 主视角要走、她让路 → 敲门/来电 → 说漏"门锁了" | 邻居姐姐、人外报恩 |
| 谈判碾压 | 主视角提出离开（辞职、分手）→ 她平静接受 | 第三方来接人 → 说漏她已经做了什么 | 大小姐、上司 |

长音声里常见的"开场已被监禁"（笼中日常型），素材里不直接演，可以放进开场字或结尾卡留白。

## 6. 表演指示词库

从原作导演注释提炼（全部 377 部里〔轻笑〕出现 759 次，是最主要的病娇信号）：

- **笑**：轻笑、笑容停住、笑着别开视线
- **语气**：语气骤冷、声音放轻、贴耳低语、一字一顿、拖长音
- **转折**：先叹一口气再变调；一句平淡的「这样啊」之后冷下来
- **动作**：凑近、攥紧袖口、背靠门、指尖搭门把、托腮盯着看、往后退半步（假装放松）
- **声音设计**：铃声停在第几声、敲门声变急、雷声、门锁声

表情幅度按人设来：温柔型的病娇不瞪眼、不狂笑；"笑容停住"比"表情扭曲"更好拍也更吓人。

## 7. 常见变体（一行一个）

- **人外**：身份放进画面（竖瞳、鳞、尾巴影子），台词里不讲设定；卡片标题不写种族，避免剧透。
- **贞操逆转 / 男女逆转**：世界观放开场字，台词照常。
- **反差人设**：王子系帅气女生、阴沉大个后辈、冷淡女仆——反差靠第一幕和第二幕的语气落差。
- **大小姐 / 上司**：用权力而不是暴力，"说漏她做了什么"比威胁更有效。

## 8. 大纲阶段合格示例

格式和写法见 `core/outline-template.md` 里的示例 A《第四声》（出轨审判型）。下面是温柔陷阱型的合格示例。

### D 《醉倒在我门口》｜邻居姐姐，温柔陷阱

- **数值**：占有欲 40 → 80 → 50 → 99
- **第一幕：她家沙发（占有欲 40）**
  - 【表演指示】你在她家沙发上醒来，她坐在地毯上托着下巴看你
  - 醒啦？你昨晚醉倒在我门口哦
  - ……这就要回去了？
  - 选项：① 嗯，我该回去了（选中，占有欲 +40）② 再睡一会儿 ③ 我怎么会在这
- **第二幕：同一个客厅（占有欲 80 → 50 → 99）**
  - 【表演指示】她别开视线笑了笑，站起身让开路（占有欲 −30）→ 画外有人敲门，女声：「你在里面吗？」（外部威胁，占有欲 +49）→ 她背靠着门，指尖搭在门把上
  - 我才没打算留你呢
  - 门也只是……顺手锁上的——（敲门声更急，打断）
  - 选项：① 开门 ② 装没听见（不点选）
- **伏笔回收**：第一幕说你"醉倒在我门口"，第二幕说漏"门锁了"，暗示你昨晚并不是自己醉倒的。
- **标题候选**：醒来在邻居姐姐家 / 她说门是顺手锁的 / 醉倒那晚，她没让你走
- **结尾卡**：你真的是自己醉倒的吗？
- **卡片标题**：温柔的邻居姐姐

## 9. 踩过的坑（问题 → 怎么改）

- 只读了参考案例的开头（旧格式案例）就开写 → 按 SKILL.md 执行协议读完全部必读文件，先交【已读确认】
- 把大纲当成松散梗概，每幕 3–5 句、塞好几个场景 → 大纲也守每幕约 10s、2 句、场景 ≤2
- 照搬长音声的下药、查手机屏幕、换锁、电视寻人新闻 → 按第 2 节压缩：改成画外音或角色本人的动作
- 数值一次跳 −60、+79，也没有反弹 → 单次 30–50，第二幕先回落再由外部威胁拉回
- 好几幕没写选项，也没标选中项 → 每幕末句抛给主视角，选项标出选中，最后一题不点选
- 最后一幕直接宣告"你是我的" → 嘴硬否认时说漏，说到一半被铃声 / 敲门打断
- 只给一个标题 → 标题 3 个候选 + 结尾卡 + 卡片标题
- 人外大纲的卡片标题写了"白蛇" → 改成「雨夜来报恩的她」，不剧透身份
- 黑化时换称呼（"男朋友君"→"你这家伙"）→ 素材里称呼全片统一，黑化靠语气骤冷
