## 案例1：吃醋女友质问（校园口语、强势语气）

### 剧情类型
冲突类型，强势女友质问主视角

### 本地化要点
- 使用常体（情侣关系）
- 女性强势语尾：`〜わよ`、`〜のよ`
- 直接质问语气

### 对照表格

| 中文 | 日语 |
|---|---|
| **标题** | **タイトル** |
| 在MiraiMind中应对吃醋女友的质问 | MiraiMindで嫉妬する彼女の質問に答える |
| **第一幕：质问开始（好感度：30）** | **好感度：30** |
| **【表演指示】**<br>（女友双手抱胸，瞪眼，语气强势） | <br> |
| 刚才那个女人是谁？ | さっきの女、誰? |
| 为什么她要跟你说话？ | 何であの子があなたと話してるのよ? |
| **【UI提问】** 女友开始吃醋质问，你怎么回应？ | **【UI質問】** 彼女が嫉妬して質問している。どう答える? |
| ① 解释<br>② 转移话题<br>③ 反问她 | ① 説明する<br>② 話題を変える<br>③ 逆に聞く |

### 本地化亮点

1. **女性强势语尾**
   - `誰?` 而非 `誰ですか?`（常体，更直接）
   - `〜のよ` 强调语气

2. **省略主语**
   - 不说 `あの女の人は誰ですか`
   - 直接说 `さっきの女、誰?`（更符合日语习惯）

3. **情侣关系用常体**
   - 全程不用敬体
   - 体现亲密关系

## 案例2：害羞告白（职场敬语、卑微语气）

### 剧情类型
告白类型，职场下属向上司告白

### 本地化要点
- 使用敬体（职场关系）
- 犹豫、结巴语气
- 谦逊表达

### 对照表格

| 中文 | 日语 |
|---|---|
| **标题** | **タイトル** |
| 在MiraiMind中向部长告白 | MiraiMindで部長に告白する |
| **第一幕：鼓起勇气（好感度：50）** | **好感度：50** |
| **【表演指示】**<br>（角色低头，双手绞在一起，声音很小） | <br> |
| 部长... 那个... | 部長... あの... |
| 我... 我一直... 喜欢您... | あたし... ずっと... 好きでした... |
| **【UI提问】** 下属向你告白，你的反应是？ | **【UI質問】** 部下があなたに告白した。どう反応する? |
| ① 接受<br>② 拒绝<br>③ 考虑一下 | ① 受け入れる<br>② 断る<br>③ 考える |

### 本地化亮点

1. **敬体使用**
   - `好きでした` 而非 `好きだった`（敬体过去式）
   - 体现职场上下级关系

2. **犹豫表达**
   - `あの...`（那个...）
   - `...` 省略号表现结巴

3. **女性自称**
   - 用 `あたし` 而非 `私`（更年轻、可爱）

## 案例3：冷艳反派勒索（嘲讽语气）

### 剧情类型
反转结构，冷艳角色勒索后被反制

### 本地化要点
- 使用常体（强势、轻蔑）
- 短促有力
- 冷嘲热讽

### 对照表格

| 中文 | 日语 |
|---|---|
| **标题** | **タイトル** |
| 在MiraiMind中反制勒索的女人 | MiraiMindで脅迫する女を逆襲する |
| **第一幕：勒索开始（警惕度：80）** | **警戒度：80** |
| **【表演指示】**<br>（角色冷笑，掏出手机，语气轻蔑） | <br> |
| 这个视频要是传出去，你就完了 | この動画が流出したら、あなた終わりね |
| 给我五十万日元 | 五十万円ちょうだい |
| **【UI提问】** 她用视频勒索你，怎么办？ | **【UI質問】** 彼女が動画であなたを脅迫している。どうする? |
| ① 报警<br>② 给钱<br>③ 假装答应 | ① 警察に通報<br>② 金を渡す<br>③ 答えたふりをする |
| **第二幕：反制揭晓（警惕度：10）** | **警戒度：10** |
| **【表演指示】**<br>【主视角】（掏出录音笔，按下播放，冷笑） | <br> |
| 【主视角】你的勒索，我全录下来了 | 【主視点】あなたの脅迫、全部録音したよ |

### 本地化亮点

1. **冷艳语气**
   - `終わりね` 带威胁感的女性语尾
   - `ちょうだい`（给我）带命令感

2. **常体体现强势**
   - 不用敬体，体现轻蔑和强势

3. **主视角反制**
   - 用常体 `録音したよ`
   - 体现掌控感

## 案例4：大小姐型角色（优雅语气）

### 剧情类型
驯化结构，大小姐从高傲到屈服

### 本地化要点
- 使用敬体但带大小姐语尾
- `〜ですわ`、`〜ざます`
- 优雅但高傲

### 对照表格

| 中文 | 日语 |
|---|---|
| **标题** | **タイトル** |
| 在MiraiMind中驯服高傲大小姐 | MiraiMindで高慢なお嬢様を調教する |
| **第一幕：高傲期（服从度：-20）** | **服従度：-20** |
| **【表演指示】**<br>（角色抬起下巴，俯视，语气高傲） | <br> |
| 你算什么东西，也配碰我？ | あなたなんて、私に触れる資格もありませんわ |
| **【UI提问】** 大小姐轻视你，怎么做？ | **【UI質問】** お嬢様があなたを見下している。どうする? |
| ① 惩罚她<br>② 无视她<br>③ 教育她 | ① 罰する<br>② 無視する<br>③ 教育する |
| **第二幕：动摇期（服从度：-10）** | **服従度：-10** |
| **【表演指示】**<br>（角色咬唇，语气不再那么强硬） | <br> |
| 我... 我不是故意的... | あたくし... わざとじゃありませんわ... |
| **第三幕：屈服期（服从度：90）** | **服従度：90** |
| **【表演指示】**<br>（角色低头，声音颤抖，完全失去高傲） | <br> |
| 我... 听您的... | あたくし... あなたに従います... |

### 本地化亮点

1. **大小姐语尾**
   - `〜ませんわ`（优雅的否定）
   - `あたくし`（大小姐自称）

2. **语气递进**
   - 第一幕：高傲（`〜ませんわ`）
   - 第二幕：动摇（`じゃありませんわ...`）
   - 第三幕：屈服（`従います...`）

3. **保持角色特色**
   - 即使屈服也用 `あたくし`
   - 不完全变成普通女性

## 案例5：关西腔角色（爽朗语气）

### 剧情类型
失败结尾，关西辣妹反杀主视角

### 本地化要点
- 使用关西腔
- 语尾 `〜やん`、`〜やで`、`〜ねん`
- 爽朗、直率

### 对照表格

| 中文 | 日语 |
|---|---|
| **标题** | **タイトル** |
| 在MiraiMind中被关西辣妹反杀 | MiraiMindで関西ギャルに逆襲される |
| **第一幕：挑衅期（好感度：10）** | **好感度：10** |
| **【表演指示】**<br>（角色双手叉腰，笑着挑衅） | <br> |
| 你一直看着我干嘛？ | ずっとウチ見てどないしたん? |
| 想搭讪就直说嘛 | ナンパしたいんやったら言いや |
| **【UI提问】** 关西辣妹挑衅你，怎么回应？ | **【UI質問】** 関西ギャルがあなたを挑発している。どう返す? |
| ① 搭讪<br>② 道歉<br>③ 反挑衅 | ① ナンパする<br>② 謝る<br>③ 逆に挑発 |
| **第二幕：暧昧期（好感度：50）** | **好感度：50** |
| **【表演指示】**<br>（角色靠近，暧昧微笑） | <br> |
| 你还挺有意思的嘛 | けっこう面白いやん |
| 要不要去卡拉OK？ | カラオケ行かへん? |
| **第三幕：反杀期（好感度：-70）** | **好感度：-70** |
| **【表演指示】**<br>（角色猛推主视角，大笑） | <br> |
| 骗你的！你以为我真喜欢你？ | 嘘やん! ウチがあんた好きやと思ったん? |
| 太搞笑了吧！ | めっちゃウケるわ! |

### 本地化亮点

1. **关西腔语尾**
   - `〜やん`（吧、呢）
   - `〜へん`（否定，相当于标准语的 `〜ない`）
   - `〜ねん`（强调）

2. **关西特有词汇**
   - `ウチ`（我，关西女性自称）
   - `どないしたん`（怎么了，相当于 `どうしたの`）
   - `めっちゃ`（非常，相当于 `すごく`）

3. **爽朗直率**
   - 关西腔给人爽朗、不拘束的感觉
   - 即使反杀也带幽默感
