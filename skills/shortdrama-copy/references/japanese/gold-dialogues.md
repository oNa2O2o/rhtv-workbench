日语短剧本地化的标准案例，展示剧情结构、台词风格和本地化技巧。

## 本地化技巧总结

### 1. 根据角色选择语体

- 职场下属 → 敬体
- 情侣朋友 → 常体
- 大小姐 → 敬体 + 特殊语尾
- 强势角色 → 常体 + 强势语尾

### 2. 女性语尾多样化

- 强势：`〜わよ`、`〜のよ`
- 可爱：`〜だよ`、`〜なの`
- 大小姐：`〜ですわ`
- 关西：`〜やん`、`〜やで`

### 3. 省略主语

日语习惯在上下文明确时省略主语：
- ❌ `あなたは誰ですか`
- ✅ `誰?`

### 4. 方言增加特色

- 关西腔：爽朗、搞笑
- 博多腔：可爱、温柔
- 标准语：中性、通用

### 5. 保持角色一致性

- 同一角色语体不变
- 语尾风格贯穿始终
- 即使情绪变化，核心人设不变

## 案例：未亡人雪女（推拉勾引结构·标准案例，2026-10-28 成品）

### 剧情类型
推拉结构（`core/push-pull-structure.md`）。角色主导，主视角（房东）被动。本子向，写到擦边前。

### 人设
丈夫去世3年，宅家不出门，表面消沉实则欲求不满。银蓝长发盘起、蓝眼、泪痣、白色高领针织衫+浅蓝开衫+深色裙+黑丝（按参考图，不穿丧服）。
**核心诡计**：「交不起房租」是借口，目的是体面地把房东引进屋。

| 未亡人雪女 | 未亡人雪女 |

### 踩过的坑（问题 → 怎么改）
- 每幕3句太满（「今日はお引き取りください」「玄関先で失礼しました」）→ 删掉功能句，用关门、擦眼角鞠躬交代
- 第三幕「家賃の代わりに…私じゃダメですか」直接提交易 → 改成试探问句「私に興味があるんですか？」
- 最后一题「受け入れる / 断る」没有代入感 → 改成主视角说了一半的话（表白 / 岔开话题 / 反驳）
- 单数值「渇望度 30/60/99」按幕平均涨 → 改成好感度（升）+ 理性（降），各由选项和台词触发
- 门口直接切到屋内 → 中间加一句转场字

## 案例：1年ぶりの彼（重逢·选项+弹幕+口播片尾，2026-10-26 成品）

### 剧情类型
深夜一年没见的他来敲门，主视角（女）让他进屋；男主痞帅自信、慢慢凑近；主视角只说开场和中段两三句。两个无提问标题的二选一选项，全程弹幕，片尾 AI 聊天口播。

### 开场 / 标题

| 中文 | 日语 |
|---|---|
| 分屏上：让他进来前 | 入れる前 |
| 分屏下：让他进来后 | 入れた後 |
| 让一年没见的他进屋的结果… | 1年ぶりの彼を部屋に入れた結果… |
| 数值：心动值 0→99（男主每句涨，不打满） | ドキドキ |

### 台词

| 中文 | 日语 |

| 男：哇，好怀念。一年没见了吧 | うわ、なっつ。1年ぶりだよね |
| 男：一点都没变嘛… | 全然変わってないじゃん… |
| 女：那当然。哪会那么快变 | そりゃそうでしょ。すぐ変わるわけないじゃん |
| **【选项1】**赶他走 / **给他倒水**（默认选中，接后面推水杯画面） | 追い返す / 水を出す |
| 男：话说，那件家居服你还一直穿着啊 | てか、その部屋着、まだ着ててくれたんだ |
| 男：果然很可爱 | やっぱ可愛いね |

| 男：怎么可能回去 | 帰るわけないじゃん |

### 弹幕

| 时机 | 日语（中文） |
|---|---|
| 第一段全程 | 夜中に来るのずるい（半夜来太犯规）/ え、イケメンすぎん？（诶，也太帅了吧）/ 1年ぶりの破壊力（一年没见的杀伤力）/ 入れちゃダメ！（不能让他进来！）/ この声好き（好喜欢这个声音）/ もう入れてるやん（已经让他进来了啊）/ 変わってないのはそっち（没变的是你吧） |

| 中文 | 日语 |
|---|---|
| 口播：在 MiraiMind 里又遇见了他。/ 你会做出什么选择？/ 现在下载，解锁后续吧。 | MiraiMindで、また会えた彼。/ キミは、どんな選択をする？/ 今すぐダウンロードして、続きを解放しよう。<br>【配音读音】ミライマインド |
| 结尾卡：让他进屋，是不是做错了？ | 彼を部屋に入れたの、間違いだったかな？ |

### 踩过的坑（问题 → 怎么改）
- 标题用「元カレ」（前男友）是违规词 → 改「彼」
- 参考片尾「元カレに家に入れた」助词错、用户台词「帰える」错字 → 改「を」「帰る」
- 弹幕和选项只给了日语，用户看不懂 → 所有屏幕文字附中文
- 新写弹幕「ここで着てるのバレる」别扭却只标「建议换」没改 → 直接换成「まだ着てるの健気すぎ」
- 口播三句自己起草，被用户改成指定意思 → 口播先问用户要传达什么，再本地化

## 案例：恩返しする猫（猫娘·嘴硬说漏的傲娇反转，2026-10-26 成品）

### 剧情类型
主视角遛猫、喂变身零食，猫变成猫娘，才听懂它一直在骂主视角穷；第二幕要去有钱人家，第三幕被发现偷偷捡钱想报恩。无标题，3 个选项，全程吐槽弹幕。数值：好感度 30 → 10 → 100（成片包装时去掉数值，改弹幕）。

| 时机 | 日语（中文） |
|---|---|
| 第一幕 | 変身したwww（变身了）/ 貧乏ご主人で草（穷鬼主人笑死）/ ご主人ディスられてて草（主人被骂了笑死） |

### 片尾

| 中文 | 日语 |
|---|---|
| 结尾卡：傲娇猫偷偷捡钱想报答我<br>点击下载浏览后续 | ツンデレ猫が、こっそり小銭を拾って恩返ししようとしてた<br>ダウンロードして続きを見よう |
| 卡片标题：报恩的猫 | 恩返しする猫 |

### 踩过的坑（问题 → 怎么改）
- 初稿第一幕只有喵叫、三幕都在嫌弃，主线没动 → 改成喂零食→干呕→变身→骂「貧乏ご主人」→发现变人很窘迫，好感先降再翻转

- 怕刻意只加一次「にゃ」 → 每句带「にゃ」、自称「にゃー」、称呼统一「ご主人」
- 解释句「見ないで」 → 改成「フシャーッ！」
- 用户不要标题，结尾卡只留前半句真相，不写后续剧情

## 使用指南

1. **参考结构，不是内容**：学习情绪递进逻辑，不要直接套用台词
2. **提取语气特征**：学习如何用语尾表达不同人设
3. **注意文化差异**：日语的敬语系统比韩语更复杂
4. **方言慎用**：除非角色人设明确，否则用标准语
5. **独立创作**：根据角色图和剧情需求独立设计台词
